# Image Prompt Patterns

Read the approved prompt lock before every generation. It must contain IP type, authorized identity anchors or representative brief, selected style fingerprint, enhanced traits, palette direction, composition, and negative constraints.

Use this consistency clause after a candidate has been selected:

`same selected IP character, consistent face, hairstyle, silhouette, proportions, outfit, palette, materials, outline treatment, accessory placement, and mascot identity`

## Six-Variant Preview Overview

Generate one 3x2 preview overview containing exactly six separate character variants with equal cell size, consistent scale, and clear gutters. Leave clear corner space in every cell for host-rendered numeric badges. The host renders numeric badges on the same overview page in reading order: `1` top-left, `2` top-center, `3` top-right, `4` bottom-left, `5` bottom-center, `6` bottom-right. Do not place a number, caption, logo, or watermark inside the generated artwork.

For 人物 IP, preserve these authorized, visible anchors: [identity lock]. For 代表形象 IP, create an original character from this representative brief: [representative brief]; do not imply a real-person likeness. Apply the selected style: [style fingerprint]. Strengthen: [enhanced traits]. Palette: [palette direction]. Use these cell focuses in order: 1 balanced default, 2 silhouette emphasis, 3 outfit emphasis, 4 accessory emphasis, 5 pose energy, 6 expression or composition emphasis. Center each character, maintain a clear readable silhouette, use [ratio] and clean [background], and include no copied character, logo, watermark, text, or extra character.

All six cells in the one 3x2 preview overview must retain the same approved source/brief, style, enhanced traits, and palette. Vary only the assigned cell focus so the options are meaningfully distinct without becoming redesigns.

## Avatar

Create one square 1:1 avatar using the selected candidate as the exact identity reference. Show a centered head-and-shoulders or bust composition with a strong readable face, the same selected style, palette, materials, outline treatment, hair, facial features, and accessories. Use a clean background appropriate to the selected style. No text, logo, watermark, extra character, or redesigned costume. same selected IP character, consistent face, hairstyle, silhouette, proportions, outfit, palette, materials, outline treatment, accessory placement, and mascot identity.

## Expression-Sticker Source Board

Create one 3x3 expression-sticker source board using the selected candidate as the exact identity reference. Expressions in reading order: Happy, Laughing, Angry, Aggrieved, Surprised, Confused, Proud, Tired, Love. Each cell contains one centered character with a clear facial emotion and supporting gesture. Keep identical face, hairstyle, silhouette, outfit, palette, material, outline, and accessory placement. Plain or transparent-looking background, equal spacing, no captions, no watermark, no logo, no extra characters. Leave a small caption-safe strip beneath each cell for later host-rendered Chinese labels. same selected IP character, consistent face, hairstyle, silhouette, proportions, outfit, palette, materials, outline treatment, accessory placement, and mascot identity.

## Final Delivery Board

After generating the formal avatar and expression-sticker source board, compose one 4x3 final delivery board. Place the square formal avatar in the left panel and the full 3x3 expression board in the right panel. Use host rendering to add Chinese captions on the same page: `正式头像` for the left panel, then `开心`, `大笑`, `生气`, `委屈`, `惊讶`, `困惑`, `得意`, `疲惫`, `喜爱` beneath the expression cells in reading order. Do not ask the image model to typeset any Chinese. Keep the page clean, evenly spaced, and suitable for direct delivery.

## Optional Cutout Export

Only when the user selects optional transparent-background cutout export, crop the nine expression cells into individual square files and remove their backgrounds. Verify each exported sticker has a real alpha channel before claiming transparency. If the user declines or skips this option, deliver only the one 4x3 final delivery board with Chinese captions.

## Drift Repair

Regenerate [the complete 3x2 preview overview / avatar / failed expression-source cell]. Compare against the selected cell and restore these locked details: [changed features]. Preserve the requested [variation / expression] while making no other redesign. Repeat the consistency clause and negative constraints. If a numeric badge or Chinese caption is wrong, recompose the overview or final delivery board with host rendering; do not regenerate the character artwork.
