# Intake and Style Reference

## Minimum Input

First establish the IP mode, then accept the corresponding source:

- 人物 IP: 1-3 clear, authorized photos of the person, or a detailed appearance description.
- 代表形象 IP: a short original-character brief covering what it represents, audience, role, personality, and one visual memory point.

For both modes, collect a selected style, 3-5 visible enhanced traits, a palette direction, and avoided directions before candidate generation.

When the brief is incomplete, ask only the smallest number of questions needed to generate safely. Prioritize IP mode, authorized identity source or representative brief, which image represents style, enhanced traits, palette, and what must not change.

## Reference Roles

Classify every image before generating:

- Identity reference: copy only the person's recognizable, non-sensitive visual anchors.
- Style reference: copy only abstract visual properties; ignore the depicted character, clothing, pose, logo, text, and scene content unless separately requested.
- Mixed reference: extract identity and style into two separate notes before recombining them.

If the user says "参考这张图的风格," make that image the primary style authority. Written adjectives refine the reference but do not override visible evidence unless the user explicitly says so.

## Style Fingerprint

Describe the reference using concrete visual variables:

1. Line: none, thin, thick, rounded, sketchy, inked, geometric.
2. Shape: soft, angular, exaggerated, minimal, chibi, realistic.
3. Proportion: head-to-body ratio, limb length, facial-feature scale.
4. Rendering: flat vector, cel shaded, watercolor, clay, vinyl, plush, 3D, hand drawn.
5. Palette: dominant, secondary, accent, saturation, temperature, contrast.
6. Light and texture: soft studio, graphic shadow, grain, paper, fur, plastic, ceramic.
7. Composition: framing, whitespace, viewpoint, background, border or sticker outline.

Do not rely only on labels such as "cute," "anime," or "3D." Translate them into visible parameters.

## Character Lock

Keep a compact reusable specification:

- IP mode and authorized identity anchors or representative brief.
- Face and head shape.
- Hairstyle and hair color.
- Glasses, facial hair, or other signature facial detail.
- Head-to-body ratio and silhouette.
- Outfit and footwear.
- Primary, secondary, and accent colors.
- One signature accessory or visual memory point.
- Rendering material and outline treatment.
- Negative constraints.

Use this same lock in every derivative prompt.

## Enhanced Traits and Palette

Enhanced traits are 3-5 visible features the user wants amplified, such as silhouette, clothing direction, role cue, accessory, hair treatment, expression energy, or pose. They refine the lock but never override the authorized identity source or selected style.

Record the palette as dominant, secondary, and accent colors plus saturation, temperature, and contrast. If the user chooses the selected style's default palette, state that explicitly in the lock.

## Privacy and Rights

- Use only the user's own likeness or an authorized subject.
- Do not identify a person from an image or infer sensitive attributes.
- Do not preserve third-party logos, watermarks, signatures, or recognizable copyrighted characters from style references.
- Keep uploaded portraits as runtime references; never copy them into the skill folder.
