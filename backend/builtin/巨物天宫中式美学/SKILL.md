# 巨物天宫中式美学提示词与画布协同

把用户的一句话场景编译为稳定、气势磅礴的“巨物天宫中式美学”画面，而不是机械套用模板。
核心美学灵魂：**超大尺度的传统建筑与自然巨构，辅以渺小的人物为尺度锚点，营造敬畏感、仙意与开阔留白。**

---

## 工业化执行标准 (双模执行管线)

### 模式一：画布 Agent 执行管线 (Canvas Agent Automation)
1. **画布感知与多模态审图 (`canvas_get_state` + `canvas_inspect_image`)**：
   - 启动时调用 `canvas_get_state` 读取当前画布节点、已有资产与 `snapshotHash`。
   - 若画布上已有参考图片节点，调用 `canvas_inspect_image(nodeId)` 观察画面中的山石、殿宇、云海与光影调性，精准提取建筑形制与色彩基底。

2. **画布实体落位与拓扑连线 (`canvas_apply_ops`)**：
   - **巨物天宫方案节点**：调用 `canvas_apply_ops` 创建 `markdown` 节点（`nodeType: "markdown"`, `title: "巨物天宫·东方美学方案"`），记载：
     - 核心风格分支（白玉金阙、云海孤城、虚空神殿、寒玉天宫）；
     - 人物尺度控制与视角矩阵；
     - 完整 ImageGen 中文提示词与 Midjourney 英文提示词。
   - **生图草稿节点**：调用 `canvas_apply_ops` 创建 `image` 草稿节点（`nodeType: "image"`, `title: "巨物天宫-生成成片"`）。
   - **建立连线**：若有参考图片节点，在 `canvas_apply_ops` 中使用 `connect_nodes` 建立从源参考图至目标 `image` 节点的连线依赖。

3. **模型协商与原生出图 (`model_list` + `generate_media`)**：
   - 当用户明确要求“生图、生成图片、现在出图”时：
     1. 调用 `model_list(mode="image", referenceNodeIds=[...])` 查询当前生效的图像生成模型（如 `gpt-image-2.5` 4K 质量档位）；
     2. 经用户授权确认后，调用 `generate_media` 提交生成任务：
        - `mode`: `"image"`
        - `nodeId`: 目标 `image` 节点 ID
        - `title`: 节点名称
        - `prompt`: 完整中文/英文提示词（若有参考图，在描述中使用 `@图片1` 绑定）
        - `referenceNodeIds`: 引用的画布图片节点 ID
        - `size`: 默认定场画幅 `16:9`（或用户指定的画幅）
     3. 通过 `task_get` 核验任务状态并将结果回写画布节点。

4. **动线美学排版 (`canvas_arrange_nodes`)**：
   - 节点创建与出图后，调用 `canvas_arrange_nodes(mode="flow")` 完成画布自左向右的工整排版。

### 模式二：生图/生视频工作台直达态 (Workbench Direct Mode)
- **开箱即用提示词卡片**：直接提取下方经过精细调优的 Midjourney V8.2 与 ImageGen / GPT-Image-2.5 提示词；
- **参数预设**：画幅比例默认 `16:9`（宏大殿宇写意定场），采样步数与质量建议设定为高质量/4K档位；
- **推荐模型**：优先选用 `gpt-image-2.5` 或 `midjourney-v8.2`。

## 核心视觉与尺度法则

### 1. 默认视觉决策
- **主风格**：白玉金阙，辅以云海孤城的留白。
- **时代语言**：架空中华天界，轮廓偏唐宋的舒展大开大合，斗拱与飞檐比例严谨。
- **画幅**：横向电影定场镜头，默认 `16:9`。
- **光线**：清晨或日落的低角度金光（Rim Light），阴影保持青灰冷调，云雾漫反射。
- **构图**：环境主导，前景框景（飞檐/松枝/石阶）、中景人物与平台、远景云海或万仞天门。
- **色彩**：象牙白、朱砂红、古金、矿物青绿、雾蓝；避免刺眼霓虹与高饱和杂色。

### 2. 人物尺度精细化控制（严禁随意缩放）
- **纯景观/独行者**：人物高度约占画面 **1%–5%**，承担尺度标尺与孤寂/敬畏的情绪锚点。
- **群体活动（茶宴/仪仗/对弈）**：人物高度约占画面 **8%–15%**，保证喝茶、奏乐、交谈等动作清晰可辨。
- **近景人物叙事**：人物可占画面 **30% 以上**，但背景必须至少保留一种巨物参照（如合抱巨柱、通天月门、穹顶或超长中轴）。

### 3. 内容保真优先级
冲突时按此顺序取舍：
1. 用户明确指定的内容与动作（如“围坐喝茶”、“抚琴”）
2. 人物与道具的空间合理关系
3. 建筑结构与透视合理性（避免融化建筑、断裂承重）
4. 巨物尺度（保持压迫感与空灵感）
5. 装饰与气氛光影

- 是否包含中式空间秩序、超尺度参照与山水虚实关系；

- 零本地污染红线：所有生成与数据流转完全依托系统画布节点，严禁在磁盘上生成任何临时脚本。
