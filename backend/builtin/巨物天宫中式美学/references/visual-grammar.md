# 视觉语法

## 核心定义

“巨物天宫中式美学”由四个同时成立的条件构成：

1. **中式空间秩序**：中轴、对称、院落递进、门洞套景、柱网、台基、飞檐和斗拱。
2. **超尺度参照**：宫阙、巨树、绝壁、云瀑、长阶、圆月或神兽与人物形成明确比例差。
3. **山水式纵深**：近景可触、中景叙事、远景虚化；云海和雾不是填充物，而是留白与空间分隔。
4. **情绪锚点**：人物正在做一件具体而克制的事，使巨构不只是空洞背景。

缺少任意两项时，不应称为本风格。

## 六个风格分支

### 1. 白玉金阙（默认）

- 场景：礼仪宫殿、天门、中轴长阶、云端回廊、白玉露台。
- 材质：象牙白玉石、朱砂木柱、古金构件、深色木顶、黑色镜面漆地。
- 光色：清晨或落日金光；阴影青灰；局部矿物青绿。
- 情绪：庄严、神圣、秩序、静谧。

### 2. 云海孤城

- 场景：空殿、断桥、悬台、远山、无尽云海。
- 构图：大面积留白，单个或极少人物，人物占画面 1%–5%。
- 光色：雾蓝、月白、淡金；低饱和。
- 情绪：辽阔、孤寂、超脱、时间停滞。

### 3. 神木仙境

- 场景：巨型古松、盘根古树、垂藤、悬崖寺观、林间天门。
- 材质：苍老木纹、青苔、岩壁、白玉栏杆、少量铜铃或玉饰。
- 光线：树冠缝隙中的体积光与薄雾。
- 情绪：生机、古老、隐秘、敬畏。

### 4. 冰雪天关

- 场景：雪谷、冰壁、白色巨龙或冰雕天门、黑色绝壁、云瀑。
- 光色：冷蓝白为主，极少暖金点光。
- 构图：人物极小，风雪和巨大垂直体量压迫画面。
- 情绪：肃杀、清寂、朝圣、边界感。

### 5. 月宫星阙

- 场景：巨月、圆形月门、星河、夜间宫阙、悬浮山峰。
- 光色：月白、深青、暗金、少量朱红。
- 构图：圆形或弧形作为主框架，避免把月亮变成普通背景贴图。
- 情绪：浪漫、清冷、遥远、神秘。

### 6. 水墨金箔（可选支线）

- 场景：人物衣袂化为山水、墨色云海、液态大漆、矿物颜料和金箔山脊。
- 材质：湿墨、半透明玉、树脂、鎏金、矿物青绿。
- 规则：仅在用户要求水墨、金箔、材质转化或更抽象时使用，不得污染默认写实仙宫。

## 建筑语言

优先使用：

- 木构柱梁枋体系、斗拱承托、深远出檐、重檐庑殿或歇山轮廓。
- 白玉台基、须弥座、云水纹或龙纹浮雕、栏板与望柱。
- 中轴门殿、回廊围合、层台递进、门窗或月门框景。
- 构件重复必须遵循结构节奏；重复不等于复制粘贴。

谨慎使用：

- 巨柱、巨墙、环形建筑和悬空平台必须有可理解的连接或承托。
- 龙纹优先作为浮雕、柱础、壁面或水口；活体龙仅在用户要求神兽时出现。
- 不把希腊罗马柱、哥特尖拱、欧洲城堡穹顶混入默认画面。

## 巨物构成方式

每张图选择一项主巨物、一项辅助巨物即可：

- 建筑巨物：天门、巨殿、长阶、环形宫城、无尽柱廊、白玉巨墙。
- 自然巨物：古松、绝壁、云海、冰川、瀑布、月亮。
- 神话巨物：鲲、鹏、龙、玄鸟、仙鹤；必须服务场景叙事。
- 材质巨物：由水、冰、云、墨、金箔或玉形成的建筑/生物。

不要同时堆叠所有巨物，避免主题失焦。

## 构图语法

- **正中中轴**：适合朝会、天门、长阶、正殿和仪式。
- **侧向消失点**：适合回廊、墙体、悬桥和行走人物。
- **门洞套景**：适合室内望向云海、月亮或远方宫阙。
- **巨树框景**：适合观景、喝茶、谈话和隐居场景。
- **低机位仰视**：强化柱、门、穹顶和悬空建筑的巨大尺度。
- **高位远眺**：强化云海、群峰、长桥和宫城层级。

除非用户要求实验构图，保持地平线、柱网与楼梯透视一致。

## 光色控制

- 默认冷暖分离：受光面暖金，阴影雾蓝或青灰。
- 红色只用于结构节点、服装或视觉锚点，避免满画面红金。
- 白玉表面保留微暖反射和石材纹理，不做塑料纯白。
- 云海保留亮部、半影和体积层次，不做一整块白色棉花。
- 夜景使用月光、灯笼或殿内暖光之一作为主光，不叠加互相冲突的太阳光。
