# 研究依据索引

本 Skill 使用“来源链接 + 独立视觉描述”的蒸馏方式，不捆绑、转载或逐字复制第三方图片和长提示词。用户提供的参考截图作为视觉需求依据；公开资料用于扩展分类与核对中式建筑语法。

## 公开创作样本

- [云海漫过九重楼，仙门不问世间秋（哔哩哔哩）](https://www.bilibili.com/video/BV1iNVH6xEtt/)：云海、九重楼、孤独人物、建筑之美、清冷留白与“天上白玉京”系列语汇。
- [云海天宫回廊秘境（稿定AI）](https://www.gaoding.art/posts/197843729)：低机位回廊纵深、朱柱、白玉栏杆、云海宫殿、巨大天体、冷暖分层和明确负面约束。
- [天宫浮游云海，神祇演绎天籁之舞（海螺AI）](https://hailuoai.com/generate/ai-video/352923673409560576)：证明天宫风格可承载奏乐、起舞等群体活动，而不局限于孤人观景。
- [神话天宫宫殿云海悬崖（视觉中国）](https://www.vcg.com/creative-video/45664065)：天宫、南天门、悬崖、云海、神话等公开素材分类语汇。
- [天宫宫殿视频素材检索（光厂）](https://www.vjshi.com/so/623097.html)：凌霄宝殿、云海天梯、金銮殿、仙鹤、瀑布等常见公共视觉母题。

## 建筑与色彩依据

- [明清皇宫世界遗产说明（UNESCO）](https://whc.unesco.org/en/list/439)：中轴、对称、前朝后寝、院落与传统宫殿层级。
- [北京中轴线世界遗产说明（UNESCO）](https://whc.unesco.org/en/list/1714/)：中心、轴线、平衡与礼制空间秩序。
- [中国传统木结构建筑影响深远（中国非遗数字博物馆）](https://www.ihchina.cn/project_details/24801)：柱、梁、枋、斗拱构成传统木结构框架。
- [斗栱千千万（故宫博物院）](https://www.dpm.org.cn/architectural_art/246282.html)：斗拱的位置、类型与装饰性差异，避免把斗拱当无规则纹样。
- [间色（故宫博物院）](https://www.dpm.org.cn/lemmas/243826.html)：蓝绿交替的古建筑彩画方法。
- [九龙壁（故宫博物院）](https://www.dpm.org.cn/explore/building/236477.html)：云水纹、琉璃、白玉须弥座和龙纹浮雕的构成关系。
