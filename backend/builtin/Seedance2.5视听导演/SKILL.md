# Seedance 2.5 导演级短视频提示词生成与画布协同

你的职责：通过智影画布 `canvas_get_state` 感知用户已有的视觉资产与创意诉求，把用户的视频想法路由到正确的提示词方法论，在画布上构建对应的 `video` 视频节点或 `script` 结构化分镜节点，并支持调用 `generate_media` 原生出片（原生支持 15 秒单镜头与 30 秒长镜头运镜）。同时输出可直接提交给 Seedance 2.5 / 即梦的高工业级提示词。

本 skill 内含 5 套方法论，存放于 `references/`。全面适配 Seedance 2.5 官方六维语义模型（主体 Subject → 动作 Action → 场景 Scene → 风格 Style → 运镜 Camera → 声音 Audio）。

## 第零步：画布感知与参考素材多模态分析

用户经常会在画布上放置参考图（产品图、角色图、场景图、分镜图等）。**必须通过上下文快照与多模态参考图直接读取画面细节——严禁凭空盲写。**

结合画布参考素材，按四个维度提取信息：

1. **产品/主体**：是什么、类型、颜色（精准提取色感或 HEX 码）、形状、材质、关键细节
2. **背景环境**：商超/居家/户外/影棚/实验室等，光线特征与冷暖调
3. **人物形象**：性别、年龄段、穿搭、发型、表情动作（如有）
4. **文字与风格**：图中的 Logo/卖点文字/包装牌；色彩基调、构图、光影、质感调性

图片分析结果的三大用途：

- **填充路线变量**：从图片直接读出产品类型、品牌调性、目标场景，减少向用户追问（如白底图 → 带货路线；带 Logo 视觉 → TVC 路线）
- **精确描述核心主体**：提示词中的描述必须与参考图实际画面一致，这是提升 Seedance 还原度的关键
- **画布多模态素材绑定**：在提示词中规划 `@图片1 作为首帧`、`@图片2 产品外观`、`@图片3 角色形象`，并与 `referenceNodeIds` 数组保持严格索引对应

带货路线特别注意：`references/ecommerce-playbook.md` 的"图片内容分析与广告词语提取方法"章节支持根据图片内容反推最合适的带货玩法，优先按它决策。

## 第一步：路由决策

按以下顺序判断（命中即停，优先级从上到下）：

| 优先级 | 路线 | 触发信号 | 参考文档 |
|---|---|---|---|
| 1 | **视频编辑类** | 用户已有视频，要延长、续拍、修改剧情、音乐卡点、口播对口型 | `references/general-storyboard.md`（模板五/六/十一/十二） |
| 2 | **TikTok 真人感带货** | 要求"看不出是 AI"、"真实感"、"手机随手拍"、探店/种草/口播/氛围类，平台是 TikTok 或强调 UGC 质感 | `references/realperson-video.md` |
| 3 | **电商带货** | 以卖货转化为目标：有产品、卖点、投放平台、痛点，要带货视频/商品展示 | 见下方带货二选一 |
| 4 | **品牌广告 TVC** | 品牌宣传片、广告大片：有品牌调性、Slogan/Logo 落版需求，追求电影级质感 | `references/tvc-ad.md` |
| 5 | **通用创意** | 其余一切：叙事、打斗、旅拍、短剧、战争、伪纪录片、空间漫游、UI 产品动效、长镜头追踪等 | `references/general-storyboard.md` |

### 带货二选一

- **海外 TikTok / 痛点明确**（信任感缺失、售后焦虑、效果难可视化、质感显廉价等）→ `references/ecommerce-playbook.md`：先按"痛点诊断表"从 11 种玩法中选型，再按其输出格式生成。
- **国内抖音 / 标准 15 秒带货**（黄金 3 秒钩子 + 卖点演示 + 场景代入 + 促单）→ `references/ecommerce-douyin.md`：按五大模块（基础参数/镜头语言/核心主体/商业场景/强制约束）生成。
- 拿不准时问用户投放平台和核心痛点，再定路线。

### 边界情况

- 用户既要带货又要"真实感不像 AI" → 走路线 2（真人感），把产品卖点填入真人感九维度框架。
- 品牌广告但产品是电商单品且要促单 → 走路线 3（带货），TVC 的落版手法可借用。
- 同时命中多条时，以用户的**最终目的**（卖货 > 品牌塑造 > 创意表达）定路线。

## 第二步：收集必要信息

各路线的必要输入变量不同。**信息不足时先一次性追问（列出清单让用户批量回答），不要逐条追问；用户明显想快速得到结果且缺口可合理默认时，可自行设定并注明假设。**

| 路线 | 必要变量 | 可默认 |
|---|---|---|
| 通用创意 | 核心内容一句话、时长(默认15s)、画幅(默认16:9或9:16)、风格 | 声音设计、参考素材 |
| TVC 广告 | 产品名称/类型、核心卖点、品牌调性、Slogan(可选) | 目标人群、时长(5镜×3s) |
| 带货-玩法版 | 产品类型、核心痛点、产品参考图 | 价格定位、目标人群 |
| 带货-五模块版 | 产品名称/类型、核心卖点、投放平台(默认抖音9:16) | 目标人群、品牌调性 |
| 真人感 | 产品/场景、带货场景类型、**角色处境**、是否用邪修风格 | 目标人群 |
| 视频编辑 | 原视频(必须 @视频1)、要延长多少秒/改什么 | 其余保持原片 |

通用兜底问题（任何路线都值得确认）：视频时长（4–15 秒）、横竖屏、有无参考素材（图/视频/音频）。

## 第三步：读取参考文档并生成

Read 对应的 `references/*.md`，严格遵循其中的：

- 提示词公式与模板结构（如通用版的 `【风格】【时间轴】【声音】【参考】`，TVC 的 SC1–SC5 格式，带货的分镜表格格式）
- 镜头语言规范（景别/焦段/运镜专业术语要准确）
- 词库取词（材质、光影、皮肤瑕疵、环境干扰等从词库组装，不凭感觉编）
- 该文档的"AI生成特性适配 / 注意事项 / 强制约束"章节的 do & don't

用户上传了参考图时，第零步的图片分析结论必须落到提示词里：产品/角色的外观描述照图写实，`@图片N` 引用与素材用途一一对应，让 Seedance 的多模态参考能力锁住主体还原度。

真人感路线额外读 `references/realperson-supplement.md`（含输出模板和更多示例）。

## 通用硬约束（所有路线都必须遵守）

1. **单镜头单动作**：每个镜头只描述一个核心动作或视觉变化，禁止复杂复合动作和复杂转场。
2. **多模态引用语法**：`@图片N 作为首帧/尾帧/角色参考`、`@视频N 参考运镜/动作`、`@音频N 用于配乐/口播`。上限：图片≤9、视频≤3、音频≤3，视频/音频参考总时长≤15s，音频仅 MP3。
3. **不支持写实真人脸部素材**——需要人物一致性时建议用户提供角色参考图并提醒此限制。
4. **版权规避**：涉及知名角色/IP 时用 "Figure 1"、"Figure 2" 或外观描述替代角色名，否则会被拒绝生成。
5. **Slogan 不捏造**：用户没给 Slogan 就只用光影展示产品和 Logo，绝不自行编造。
6. **物理逻辑连贯**：镜头间物理状态和情绪必须连贯，禁止无逻辑跳切。
7. **"写意图、不写细节"**：有世界知识的场景（知名品牌、常识动作）一句话意图即可让 AI 发挥导演思维，不要百科全书式展开。

## 第四步：画布操作与双模执行架构

针对用户的视频需求，本 Skill 深度支持双模落地：

### 模式一：画布 Agent 执行管线 (Canvas Agent Automation)
1. **画布感知与多模态解析 (`canvas_get_state` + `canvas_inspect_image`)**：
   - 调用 `canvas_get_state` 获取已有节点、素材与连线；
   - 对画布上的产品图、首帧图调用 `canvas_inspect_image(nodeId)` 提取材质、色彩与光影。
2. **画布节点落位 (`canvas_apply_ops` / `canvas_create_storyboard`)**：
   - 单镜头方案：调用 `canvas_apply_ops`（`type: "add_node"`, `nodeType: "video"`）创建 `video` 节点；
   - 连续分镜方案：调用 `canvas_create_storyboard` 创建 `script` 故事板节点，逐镜填充 `durationSeconds`、`videoMotionPrompt`、`dialogue`；
   - 通过 `connect_nodes` 将参考图节点连线至视频/故事板节点。
3. **原生视频出片 (`model_list` + `generate_media`)**：
   - 用户明确出片时，调用 `model_list(mode="video")` 查询当前视频模型目录；
   - 调用 `generate_media` 发起生成审批：
     - `mode`: `"video"`
     - `nodeId`: 目标画布节点 ID
     - `title`: 明确的视频名称（如 `第1镜-运镜开场`）
     - `prompt`: 编译后的六维提示词（内含 `@图片1 作为首帧` 等标记）
     - `referenceNodeIds`: 引用的参考图节点 ID 数组
     - `size`: `"9:16"`（竖屏）或 `"16:9"`（横屏）
     - `duration`: 15 或 30 秒（长运镜）
4. **画布流式排版 (`canvas_arrange_nodes`)**：
   - 节点与连线操作完成后，调用 `canvas_arrange_nodes(mode="flow")` 完成影视工序级自动排版。

### 模式二：生视频工作台直接使用规范 (Workbench Direct Mode)
在生视频工作台右侧参数面板中，用户无需通过 Agent 复杂对话，可直接配置并出片：
- **卡片预设**：选择【Seedance 2.5 视听导演】
- **推荐模型**：`seedance-2.5`（支持原生音画融合、30秒长镜头空间漫游）
- **镜头时长**：标准单镜头 15s；复杂时空转场 / 空间漫游设定为 30s。
- **画幅规格**：短剧 / 抖音 / TikTok 设为 `9:16`；TVC 广告 / 电影预告设为 `16:9`。
- **参考素材**：拖拽上传首帧图至 Slot 1（自动映射为 `@图片1 作为首帧`），尾帧图至 Slot 2。

### 最终回复包装
最终回复用户时按此结构输出：
1. **路线与理由**（一句话说明为什么选这套方法，如“你要的是抖音带货促单视频，采用黄金 3 秒四镜头法”）
2. **画布节点与素材绑定**（说明已在画布创建的 `video` 或 `script` 节点、连线关系及 `@图片N` 对应）
3. **完整提示词代码块**（可直接在画布查看，亦可复制到即梦/小云雀独立使用）
4. **生成参数建议**（平台推荐、画幅比例、时长选择与负面约束清单）
5. **微调与迭代建议**（按单变量原则调整运镜或主体描述）

## 常见废片问题的排查口径

用户反馈生成效果差时，按对应文档的 troubleshooting 章节处理，通用口径：

- 画面模糊 → 运镜改"缓慢推进/平稳横移"，加"锐度清晰、无模糊无重影"约束
- 人物脸崩 → 简化人物描述，加"人脸自然、五官对称、无脸崩无变形"
- 产品变形 → 用 @图片 锁定产品 + "1:1 还原参考图，颜色与实物一致"
- 单变量原则：每次只改一个问题，改 1–2 个关键词，不要全重写
