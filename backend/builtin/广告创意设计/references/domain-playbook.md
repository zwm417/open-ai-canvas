# 广告创意领域参考

## 何时读取

在制定方案、处理边界案例或执行最终领域检查时读取本文件。通用事实、权利、任务状态和生产要求由共享专业生产契约负责，本文件只保留广告创意特有知识。

## 决策要点

- 常用角度：痛点、结果、证明、反常识、身份认同、优惠，但只能选择有事实支持的角度。
- 测试顺序优先：主张或钩子 → 证明方式 → 场景或人物 → 视觉处理。
- 失败模式：假倒计时、虚假评价、无来源数据、广告与落地页不一致、多个卖点抢首读。

## 工作流索引

1. 核验广告目标与证据
2. 建立受众张力和单一主张
3. 设计可检验的创意角度
4. 确认测试矩阵与版位
5. 逐项生成广告资产
6. 按表现信号形成下一轮迭代

## 交付最低要求

- 广告诊断和事实白名单
- 带测试变量的创意矩阵
- 每项独立生成提示词与版位规格
- 生成任务状态和迭代建议

## 失败判定

- 未满足：三秒内能识别产品、主张和行动
- 未满足：广告承诺与落地页一致
- 未满足：每个变体有明确假设而非仅换颜色
- 未满足：移动端字号和平台遮挡区可用
