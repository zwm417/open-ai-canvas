# 宋式田园美学 · 视听提示词与画布协同系统

将用户的简短生活片段（如“雨后摘豆角”、“溪边烹新茶”）或参考图，编译为典雅、质朴而富有诗意的宋式乡居美学视觉作品。
坚持“市井田园而非皇家宫廷”、“真实劳作而非摆拍模特”的视觉哲学，在智影画布上实现从创意感知、节点落位到原生图像生成的全流程闭环。

---

## 工业化执行标准 (双模执行管线)

### 模式一：画布 Agent 执行管线 (Canvas Agent Automation)
1. **画布感知与多模态审图 (`canvas_get_state` + `canvas_inspect_image`)**：
   - 启动时调用 `canvas_get_state` 读取当前画布节点、已有资产与 `snapshotHash`。
   - 若画布上已有用户上传的人物、陶器、庭院或场景图片节点，**必须调用 `canvas_inspect_image(nodeId)` 观察真实画面**：
     1. **人物与劳作状态**：眼神与双手是否自然专注于手中的农具、柴火或茶壶（不刻意直视镜头，拒绝浓妆与假发感）；
     2. **服饰与材质肌理**：米白粗麻、苔青色棉布、粗陶罐粗糙颗粒、斑驳竹编与温润木器；
     3. **环境与自然采光**：漫射天光、江南水汽微雾、白墙黑瓦的浅灰过渡与青石板反光。
   - 将提取到的真实视觉事实准确注入提示词中，杜绝凭空脑补。

2. **画布实体落位与拓扑连线 (`canvas_apply_ops`)**：
   - **美学方案节点**：调用 `canvas_apply_ops` 创建 `markdown` 节点（`nodeType: "markdown"`, `title: "宋式田园·美学方案"`）：
     - 记录场景补全事实（人物人数、时令节气、手物接触关系、环境空间）；
     - 记录固定视觉 DNA（米白苔青主调、暖木冷水互补）；
     - 输出 ImageGen 中文原生提示词与 Midjourney V8.2 提示词及负面漂移约束。
   - **生图资产卡 / 批量创作表**：
     - 单张画面：调用 `canvas_apply_ops` 创建 `image` 草稿节点（`nodeType: "image"`, `title: "宋式田园-场景画面"`）。
     - 组图/系列画面：调用 `canvas_apply_ops` 创建 `batch-table` 节点（`nodeType: "batch-table"`, `title: "宋式田园-四季系列表"`），以便批量生成多组镜头。
   - **建立连线**：若有参考图片节点，在 `canvas_apply_ops` 中使用 `connect_nodes` 建立从源参考图至目标 `image` 或 `batch-table` 节点的连线依赖。

3. **模型协商与原生媒体生成 (`model_list` + `generate_media`)**：
   - 当用户确认需要出图时：
     1. 调用 `model_list(mode="image", referenceNodeIds=[...])` 查询当前生效的高画质生图模型（如 `gpt-image-2.5` 4K 或相关特惠渠道）；
     2. 调用 `generate_media` 发起生成审批与任务提交：
        - `mode`: `"image"`
        - `nodeId`: 目标 `image` 节点 ID
        - `title`: 节点名称（如 `雨后摘豆角-晨光清露`）
        - `prompt`: 完整提示词（若有参考图，在对应描述中精准标注 `@图片1`）
        - `referenceNodeIds`: 引用的画布图片节点 ID
        - `size`: 默认 `16:9`（宽幅写意空间）或用户指定的比例
   - 生成任务自动进入智影审批与渲染管线，通过 `task_get` 核验任务状态并将结果回写画布节点。

4. **动线美学排版 (`canvas_arrange_nodes`)**：
   - 节点创建与生成后，调用 `canvas_arrange_nodes(mode="flow")` 完成画布自左向右的工整排版。

### 模式二：生图/生视频工作台直达态 (Workbench Direct Mode)
- **开箱即用提示词卡片**：直接提取下方经过精细调优的 Midjourney V8.2 与 ImageGen / GPT-Image-2.5 提示词；
- **参数预设**：画幅比例默认 `16:9`（宽幅写意空间），采样步数与质量建议设定为高质量/4K档位；
- **推荐模型**：优先选用 `gpt-image-2.5` 或 `midjourney-v8.2`。

## 宋式田园视觉 DNA 核心法则

撰写提示词时，必须严格遵守以下美学锚点（参考 [`references/style-foundation.md`](references/style-foundation.md) 与 [`references/core-anchors.json`](references/core-anchors.json)）：

1. **朴素民居而非宫廷华贵**：绝不出现金碧辉煌的雕梁画栋或厚重金器，唯有白灰墙、老黑木、竹编、粗陶、黛瓦与青石。
2. **自然不作态的人物状态**：目光自然落在手头事务（择菜、摇扇、煮水、补网）或身边同伴上，神态宁静舒缓。
3. **米白与苔青的服饰色彩**：女性常服以米白色、浅苔青麻布为主；男性为粗布茶褐或靛蓝，质朴无华。
4. **温润通透的自然光影**：柔和的自然漫射光，被窗棂或树影轻微过滤；阴影处有清透的环境冷光补充。
5. **虚实掩映的空间构图**：善用前景景物（如微虚的南瓜藤、竹篱笆、粗陶瓦罐）形成画框，增强画面的宁静纵深感。

## 双模型提示词工程规范

### 1. Midjourney V8.2
- **结构**：`景别与视点 -> 人数与站位 -> 动作与手物关系 -> 角色状态 -> 服饰体系 -> 场景与材质 -> 动量物理 -> 光色与虚实 -> 情感基调 -> 排除项 -> --ar 16:9 --s 120 --v 8.2`
- 纯正英文，词数建议 110-180 词，**必须严格以 `--v 8.2` 结尾**。
- 绝不使用 `masterpiece`、`8K`、`photorealistic` 等通用无效占位词。

### 2. ImageGen 中文提示词
- **结构**：`画幅与空间几何 -> 明确人物数量与位置 -> 细腻手部与动作接触 -> 衣物材质细节 -> 农居环境材质 -> 自然光线与柔和色调 -> 画面情绪 -> 针对性负面约束`
- 原生中文影视文学质感，绝不机械直译英文，不得混入 Midjourney 参数。

## 画布交付前自检清单

1. **事实保真**：用户给出的农事活动、器物与节气是否完整体现；
2. **拒绝过度装饰**：是否避免了汉服摆拍、影楼假发、唐风浓妆或仙侠飘带；
3. **手物关系物理可信**：动作是否落在真实受力点（如“双手稳稳托住粗陶罐边缘”）；
4. **零本地命令行依赖**：严禁调用本地 PowerShell/Python 脚本，所有质检与逻辑闭环在系统画布内完成。
