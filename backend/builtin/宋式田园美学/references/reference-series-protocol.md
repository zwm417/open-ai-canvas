# 参考图与系列扩展协议

## 每张图分别检查

先查看完整画面，再检查人物、脸部、头发、手部器物、服装层次、前景遮挡、背景建筑和光影区域。截图界面、黑边、文字和查看器控件不属于画面内容。

为每张参考图记录：

- 原始比例和真实画面边界；
- 人数、人物位置、身体裁切、朝向、视线和动作；
- 最重要的手部或空间关系；
- 前景、中景、背景和清晰度分配；
- 服装颜色、材质、层次和运动；
- 主光方向、环境补光、树影与调色角色；
- 可见事实、不确定项和允许创作项。

不要通过“宋式”“电影感”这些标签替代画面结构。

## 冻结系列母体

从被接受的参考图或提示词中冻结：

- 人物存在感与面部状态；
- 发型轮廓和碎发方向；
- 米白、苔绿及其他配色角色；
- 服装层次与棉麻重量；
- 白墙、深木和乡居材质逻辑；
- 前景遮挡、浅景深、光晕和颗粒；
- 普通劳动被诗意观看的叙事关系。

不要冻结每一道褶皱、每一片叶子或每一粒尘埃。

## 允许变化

一次改变一至三个变量族：

- 景别和机位；
- 人数及人物位置；
- 动作与器具；
- 季节、时段、天气；
- 庭院、厨房、田野、水乡或山地；
- 前景植物与建筑取景；
- 动作强度。

如果所有变量同时改变，系列会失去母体。

## 系列提示词顺序

`本帧景别和动作变化 -> 冻结的人物与衣装 -> 关键接触关系 -> 动作产生的头发、衣料、液体或尘埃反馈 -> 冻结的配色和光学身份 -> 本帧情绪 -> 参数`

不要把同一个母提示词完整复制到每一张。开头必须让每张图的动作和景别差异一眼可见。

## 连续性检查

1. 主角的米白与苔绿识别关系是否仍存在？
2. 发型、面部气质与服装重量是否属于同一个系列？
3. 新动作是否产生可信的手部关系与次级动态？
4. 群像人数是否准确，人物是否有独立动作？
5. 近景是否保留了参考图的人物存在感，而不是变成影楼写真？
6. 远景是否保留母体，而不是变成泛化风景画？
7. 白墙、深木、竹、陶、石和植物是否维持同一世界逻辑？
8. 每一帧是否真正不同，又没有改变整个世界？
