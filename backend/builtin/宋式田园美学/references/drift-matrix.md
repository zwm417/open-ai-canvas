# 宋式田园跑偏矩阵

只修复导致当前失败的最小原因。不要在一次修复中重写整条提示词。

| 失败表现 | 常见原因 | 优先修复 | 不要做 |
|---|---|---|---|
| 人数增加或减少 | 人数出现太晚，群像关系含糊 | 把精确人数放在首句；分配独立位置、动作和视线 | 只补`exactly`而不写人物关系 |
| 景别过近 | 动作和美貌词压过环境结构 | 首句写身体占比、环境份额和负空间 | 继续添加景深与美颜词 |
| 主角苔绿色消失 | 颜色只写成全局调色 | 把苔绿绑定交领、袖缘或内层衣装 | 增强整幅绿色饱和度 |
| 变成唐风或影楼汉服 | 华丽、飘逸、美人等泛化词吸引错误风格 | 明确朴素宋式交领、棉麻宽袖、无华丽首饰 | 堆叠更多“古风”“国风” |
| 变成宫廷或园林 | “宋代”被模型理解为上层建筑 | 强调 modest rural courtyard、whitewashed walls、weathered timber | 添加亭台楼阁、雕花屏风 |
| 变成仙侠 | 空灵、仙气、飘逸使用过量 | 改成自然微风、真实重量、普通劳动 | 添加魔法粒子和大面积云雾 |
| 全员看镜头 | 没有为每人指定视线对象 | 视线分别绑定手中动作、同伴或作物 | 只写 candid |
| 手与器物混乱 | 只列器物，没有接触关系 | 写双手、左右位置、受力和器物朝向 | 增加更多道具 |
| 动作僵硬 | 没有次级物理反馈 | 从动作推导袖口、发丝、水、蒸汽或谷尘 | 粘贴通用动态词尾 |
| 肤质塑料 | flawless、porcelain、hyperrealistic等词过强 | 使用自然连续明暗、轻微真实纹理、柔和补光 | 用更多皮肤质量标签修复 |
| 颜色过艳 | 金色夕阳、鲜艳植物和衣装同时抬高 | 恢复米白主色、苔绿识别色和暖木点缀 | 直接降低所有亮度 |
| 画面太暗 | 把“电影感”误写成低曝光 | 加入白墙或天空柔和补光、保留中间调 | 加霓虹或人造轮廓灯 |
| 前景遮住人物 | 前景词过多、未限定占比和模糊 | 指定少量柔焦枝叶位于画框边缘 | 删除全部前景层次 |
| 每张图都一样 | 固定了动作、蒸汽、风和镜头 | 只冻结视觉DNA，改变1至3个变量族 | 更换整个配色和世界设定 |
| 农具不合理 | 混入现代器械或手部关系缺失 | 使用竹、木、石、陶、旧铁并写清用途 | 宣称未经确认的精确历史器型 |

## 负面约束原则

负面词只针对最近风险：

- 人数、姿势、景别或方向；
- 宫廷、唐风、仙侠或现代物件；
- 错误材质和不合理工具；
- 过饱和、塑料皮肤或时装摆拍；
- 额外主体、文字和水印。

避免粘贴通用手指缺陷大全。正向关系清晰通常比长负面表更有效。
