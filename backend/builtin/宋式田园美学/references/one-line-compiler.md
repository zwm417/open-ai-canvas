# 一句话自动编译器

使用本协议处理一句话、短语或只有动作名的输入。目标是直接生成完整提示词，不要求用户补写摄影、服装、材质和光线术语。

## 1. 提取显式槽位

按以下字段读取输入，未出现的字段保持空缺，不能覆盖用户已写内容：

```json
{
  "people": "人数与人物关系",
  "action": "主要劳动或生活动作",
  "object": "核心器具或作物",
  "place": "室内、庭院、田间、水边或山地",
  "season_time_weather": "季节、时段、天气",
  "shot_viewpoint": "景别和机位",
  "emotion": "叙事情绪",
  "ratio": "目标比例"
}
```

只有动作或名词也属于有效输入，例如：`采茶`、`雨天晾衣`、`院中煮茶`。

## 2. 匹配场景预设

在 `scene-presets.json` 中按触发词寻找最接近的一项。匹配优先级：

1. 完整动作短语；
2. 核心动词与器物；
3. 场所与时段；
4. 同类劳动的最近预设。

预设只补空缺槽位。用户指定的正面特写、三人群像、雨天、冬季或其他条件始终优先。

若没有准确预设，先归入厨房、庭院、田间、山地、水乡、纺织手作、收获加工或归家休憩，再从该类规则中补全。

## 3. 默认推断

### 人数

- 需要细腻手部关系的家务：默认1人。
- 可自然协作的清洗、推磨、纺织、采摘：默认2人。
- 喝茶闲谈：默认3至4人。
- 晒谷、插秧、收割等集体农事：默认3人，除非镜头需要一个明确前景主角。

### 景别

- 浇花、缝衣、理茶、择菜等手部细节：中近景或胸像特写。
- 炒菜、磨豆、织布等人物与器具关系：中景。
- 晾衣、提篮归家、田埂行走：全身环境镜头。
- 田间劳动、山地茶园、水乡舟行、庭院群聊：宽幅环境镜头。

### 时间与光线

- 厨房：清晨窗光或日落前侧光。
- 庭院：夏日午后筛光；若无季节，不必硬写夏季。
- 田间：清晨或傍晚斜光。
- 茶桑山地：晨间侧逆光或薄雾散射光。
- 雨天：柔和灰白天空光、湿润反射和低反差，不强加金色逆光。
- 夜间：油灯或灶火为暖色局部光，庭院保持深蓝灰环境，不变成奇幻夜景。

### 人物与服装

有人物且用户未指定时，使用自然年轻女子；群像可加入年龄相近的邻家姑娘。不要凭服装推断真实身份、精确年龄或族群。

默认衣装为米白宽松宋式棉麻外袍、苔绿或黛绿交领内层、宽袖和自然褶皱长裙。劳动需要时合理卷袖、束裙或加素色围布，但不能出现现代剪裁。

### 比例与参数

- 默认比例16:9。
- 文字创作默认 `--s 150`。
- 严格参考图默认降低风格化强度。
- 不自动添加seed、Style Reference、图片URL或`--raw`。

## 4. 建立关系骨架

至少写清一个关系句：

`人物或双手 -> 动作 -> 器物、作物或同伴`

群像必须写每个人的独立关系，例如：

- 前景女子双手摊开湿布；
- 左后方女子扶住竹篮；
- 右后方女子把洗净蔬菜递给同伴。

不得只写“三个女子在劳作”，否则人物容易增加、复制动作或全员看镜头。

## 5. 推导物理反馈

动作决定次级动态：

- 倾倒：液体或谷物轨迹与容器角度一致；
- 洗涤：湿布或菜叶下坠，水滴和涟漪从手部关系产生；
- 翻炒：蒸汽和菜叶翻动集中在锅上方；
- 行走：发丝和衣摆沿同一风向，篮筐有重量感；
- 采摘：一只手稳定枝条，另一只手摘取，篮筐位于合理承接位置；
- 扬晒：谷尘只在筛、扬、耙动作附近被逆光照亮；
- 纺织：线、梭、织物张力与手势连续；
- 舟行：船篙、船身、水纹和人物重心一致。

每张图选择与动作相关的两至三项，不复制完整气氛尾巴。

## 6. 选择词库

先读 `lexicon-index.json`，再在相关JSON中查找类别。每张普通提示词建议使用：

- 12至18个正向核心词组；
- 4至8个场景扩展词组；
- 4至8个最相关的负面限制。

不得因为词库中存在某词就强行使用。冲突时优先级如下：

`用户明确要求 > 画面或参考证据 > 场景预设 > 固定风格默认值 > 可选扩展词`

## 7. 输出前自检

- 一句话中的核心动作有没有被替换？
- 人数、主体位置和景别是否在提示词开头可见？
- 手与器物能否被理解为同一个连续动作？
- 服装、材料、光色和镜头是否共同指向宋式田园，而不是普通古装？
- 有没有无关的蒸汽、水珠、花瓣、雾或风？
- 是否避免所有人物统一看镜头？
- Midjourney是否以`--v 8.2`结束？

只有当输入中的显式现代物件、跨时代设定或人物关系与纯宋式乡居发生决定性冲突时，才需要询问；普通信息缺失应直接推断。
