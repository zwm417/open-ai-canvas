# Amazon Listing 槽位手册

当任务涉及亚马逊套图规划、逐张 Storyboard 或单槽位出图时，使用这份手册来分配职责。

## 可选槽位职责库

以下是职责参考，不是固定套图、固定数量或默认顺序。先核验目标站点当前政策，再按商品和转化问题选择必要槽位。

| 槽位类型 | 可能承担的任务 | 画面重点 | 文字规则 | 禁区 |
|---|---|---|---|---|
| S1 主图白底 | 解决“卖的是什么” | 产品完整可见，占画面约 80%-90%，纯白底 | 不加文字 | 不加 props、角标、场景、拼贴、水印 |
| S2 核心卖点图 | 解决“它最值得买的理由” | 主体 + 一个核心利益点 | 3-5 条短 callout | 不做功能堆砌，不做说明书墙 |
| S3 场景使用图 | 解决“它在哪里、怎么用” | 一个真实可信场景，产品是主角 | 可有 1 组标题 + 辅助短句 | 不要多场景拼贴，不要让环境抢主体 |
| S4 细节特写图 | 解决“它做工/结构凭什么更好” | 放大一个材质、接口、纹理、机制 | 1-3 条短说明 | 不要多细节九宫格 |
| S5 尺寸/适配图 | 解决“适不适合我” | 尺寸线、手持比例、真人比例或空间比例 | 文案极简，数字优先 | 不要同时塞多种对比逻辑 |
| S6 包装/配件或对比图 | 解决“买到什么 / 和普通款差异” | 平铺、整齐陈列或客观参数对比 | 允许清单式短文案 | 不要虚构赠品，不要贬低竞品 |
| S7 A+ 模块图 | 解决“品牌与深层转化” | 更完整的生活方式叙事或机制拆解 | 可有标题、副标题和段落级短文案 | 不要做一整页超长详情拼版 |

## 常见槽位判断规则

- 用户说“主图 / 白底图 / 首图”时，优先用 S1
- 用户说“卖点图 / 信息图 / 功能图”时，优先用 S2
- 用户说“场景图 / 使用图 / lifestyle”时，优先用 S3
- 用户说“细节图 / 特写 / close-up”时，优先用 S4
- 用户说“尺寸图 / 对比图 / scale”时，优先用 S5
- 用户说“包装图 / 配件图 / in the box”时，优先用 S6
- 用户说“A+ / 品牌模块 / 详情模块”时，优先用 S7

## 文案长度建议

- 主图：0 行
- 卖点图：标题 1 行，辅助点 3-5 条，每条尽量不超过 8 个汉字或 5 个英文词
- 场景图：标题 1 行，副标题 1-2 行
- 细节图：1-3 条短说明，尽量贴近对应结构
- 尺寸图：数字优先，描述只做必要解释
- 包装图：清单式短标签即可
- A+ 模块图：允许更完整层级，但避免变成长篇说明书

## 构图提醒

- 主图用最稳定的正视、三分之二侧视或俯视，优先让商品一眼清楚
- 卖点图保持“产品 hero + 一条主利益”的单核结构
- 场景图先保证环境真实，再追求氛围
- 细节图尽量让放大区域与整体结构逻辑连贯
- 尺寸图优先解决理解成本，不要炫技
- 包装/配件图以整洁、完整、可核对为第一原则

## 去重原则

同一套图里不要重复这些内容：

- 同一个场景反复换角度
- 同一个卖点反复换文案
- 同一张图同时承担“场景 + 尺寸 + 配件 + 参数”
- 每张都用同一版式，只是换一下标题
