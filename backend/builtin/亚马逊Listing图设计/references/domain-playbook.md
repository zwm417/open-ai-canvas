# 亚马逊 Listing 视觉系统领域参考

## 何时读取

在制定方案、处理边界案例或执行最终领域检查时读取本文件。通用事实、权利、任务状态和生产要求由共享专业生产契约负责，本文件只保留亚马逊 Listing 视觉系统特有知识。

## 决策要点

- 先判断购买障碍，再选择槽位。
- 尺寸与对比必须有真实数据；缺少时改为非量化表达。
- 场景图保持商品尺度可信，A+ 不能借 MAIN 规则做伪合规。

## 工作流索引

1. 锁定 SKU 与到手内容
2. 核对目标站点和类目规则
3. 诊断购买障碍与现有槽位缺口
4. 确认 Listing/A+ 槽位矩阵
5. 逐槽位生成独立资产
6. 执行政策、身份与可读性检查

## 交付最低要求

- SKU 身份锁与证据白名单
- 槽位矩阵和每图职责
- 逐槽位画面、文案与生成提示词
- 合规和连续性检查

## 失败判定

- 未满足：MAIN 槽位符合目标站点当前要求
- 未满足：未知配件和性能不被生成
- 未满足：每张图解决一个购买问题
- 未满足：套图共享同一商品和视觉系统
