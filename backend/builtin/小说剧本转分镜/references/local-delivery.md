# 智影画布与分镜交付规范

本文件是分镜剧本在智影（media-lab）中沉淀与交付的权威规则。

## 一、交付时机与载体

- 每个通过内容核验的完整分镜或批次，直接交付至智影画布的 `script` 结构化节点。
- 每个镜头必须包含精确的时长估算（`durationSeconds`）、运镜与主体动作提示词（`videoMotionPrompt`）及对白台词（`dialogue`）。
- 聊天对话正文、画布分镜节点与导出文件必须保持绝对一致，不分别生成两份漂移版本。

## 二、画布节点落位规范

1. **结构化分镜节点 (`script`)**：
   - 逐镜录入标准镜头数据；
   - 支持无缝连接至 `storyboard_video` 节点进行实时出片。
2. **场景故事板节点 (`styleboard`)**：
   - 承载项目画风、时代氛围与影调基准。
3. **角色档案卡片 (`character_cards`)**：
   - 锁定角色外观、服装道具与身份特征，保障跨镜头人物一致性。

## 三、分镜命名与导出规范

导出文件默认格式：
```text
{项目名}_分镜剧本_{制式}_{交付去向}.md
```
- 制式：`16x9横屏精品剧` 或 `9x16竖屏短剧`；
- 交付去向：`AI导演接力版` 或 `完整执行分镜版`；
- 用户可通过画布工作台界面一键导出为标准 Markdown、CSV 或直接推送到视频生成管线，无须 Agent 访问本地磁盘。
