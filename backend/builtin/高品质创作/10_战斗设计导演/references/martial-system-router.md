# 武学、兵器与能力体系路由

本路由用于把人物转化为动作语言，不是固定流派强弱表，也不是招式百科。

## 先选运动身份，再选名称

用以下轴线描述角色：

- 距离：贴身 / 中距 / 远距 / 可变距；
- 路径：直线 / 弧线 / 螺旋 / 多轴 / 空间跳点；
- 发力：整合爆发 / 连锁加速 / 借力转移 / 弹性回收 / 重量坠压；
- 节奏：持续压迫 / 断续试探 / 后发反击 / 假节奏 / 积累释放；
- 防御：格挡 / 偏转 / 消解 / 闪避 / 吸收 / 以攻代守 / 空间隔绝；
- 控制：关节 / 重心 / 路线 / 视野 / 武器 / 资源 / 地形；
- 风险：稳健 / 交换 / 赌博 / 自损 / 不杀 / 必杀。

名称只有在能进一步限定动作、文化、训练和人物经历时才有价值。

## 徒手体系的功能族

- 短桥贴身：抢中线、连续短打、粘连感知、近距封手。
- 整体爆发：短准备、整身同向、直入破势。
- 借力转化：听劲、让位、改向、以小位移改变大结果。
- 环绕换位：斜入、转背、绕轴、持续改变正面。
- 长距重击：腿、膝、肘、摆动和近身缠斗的高代价交换。
- 地面控制：抱摔、固定、绞控、位置优先。
- 失序伪装：醉、眠、伤、弱、慌等表象掩盖真实节奏。
- 节奏舞动：旋转、弹跳、倒立、假开放空间，用注意力控制对手。

可以组合，但必须确定主语法与辅语法。不要让人物为了展示资料库而每场换流派。

## 兵器体系的功能族

- 剑：线、点、距离、方向改变、精确控制。
- 刀：切断、压迫、承诺式重击、动量处置。
- 枪/矛：中心线、威胁半径、进退和连贯追击。
- 长柄重兵：惯性、扭矩、扫域、落点和回收代价。
- 链/鞭/软兵：延迟、缠绕、不可预测轨迹、回收风险。
- 双持：左右任务分工、节奏叠加、资源管理，不等于攻击翻倍。
- 盾/护具：改变路线、压缩空间、保护对象、创造推进面。
- 投射/弓/枪械：视线、掩体、弹药、时间窗和位置暴露。
- 飞行/念控武器：多实例、所有权、轨迹、遮挡、回收与注意力负荷。

兵器必须影响站姿、转身半径、手部占用、回收、地形和保护能力，否则只是皮肤。

## 超自然能力的战术族

- 火：占区、传播、耗氧、逼路线、持续代价。
- 水：流向、包裹、承载、压力、介质连接。
- 冰：冻结自由度、建立支撑、制造脆性和滑移。
- 风：压力差、轨迹偏转、升力、隔绝和感知。
- 雷：传导路径、麻痹、瞬时抢先、设备/金属风险。
- 土/石：支撑、质量、地形重构、掩体和动量。
- 光：视野、暴露、影子、聚焦、折射和权限。
- 暗/影：遮蔽、连接、缺失、恐惧和空间误判。
- 空间：邻接关系、门槛、方向和代价。
- 时间：先后、窗口、重复、代价和认知差。

能力设计先回答它改变哪种战术变量，再回答看起来怎样。对关键能力继续明确Trigger、Occupancy、Pressure、Counterplay、State Change与Persistence；视觉实现交给05。若能力拥有独立几何、运动、持续状态与交互边界，可按VFX Actor设计。详见`combat-vfx-co-design.md`。

## 世界与文化绑定

原创体系还要回答谁能学、训练改变什么、它在生活/礼俗/职业/黑市/权力中留下什么、有哪些伦理禁区和资源成本、同一体系的不同人物为何仍打得不同。

不直接移植项目专属角色、版权化招式名或其他作品的标志动作；只学习机制。
