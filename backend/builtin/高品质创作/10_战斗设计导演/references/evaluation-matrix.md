# 战斗设计质量与压力测试矩阵

## 评分维度

每项0—4分，0为缺失，4为稳定成立。

| 维度 | 4分标准 |
|---|---|
| 叙事必要性 | 删除战斗会改变故事，胜负条件不等于简单击倒 |
| 战斗人格 | 不看姓名也能凭选择、距离和节奏区分角色 |
| 武学绑定 | 体系来自人物/身体/世界，并稳定约束动作 |
| 对位反制 | 优势、识别、适应和代价均有可见因果 |
| 阶段升级 | 每阶段使旧方法失效或改变胜负条件 |
| 状态连续 | 位置、伤势、资源、武器、信息和关系不漂移 |
| 世界战术化 | 世界规则改变选择，并对双方对称生效 |
| Combat–VFX共设计 | 关键能力具有战术功能、空间占用、对手响应、反制与持续成本，删除VFX后因果明显残缺 |
| VFX Actor语义 | 复杂对象的所有权、拓扑、运动、交互顺序与状态不靠名称猜测 |
| 战斗奇观匹配 | 视觉规模、位移跨度、能力占区、环境参与和摄影危险度符合用户目标，不因求稳无因降档 |
| 视觉饱和预算 | 高潮由同一因果下的多层画面事件构成，主体/主攻击仍可读，非无差别堆爆炸 |
| 大招终结 | 有前置、权限、交互、代价、结果和残留 |
| 人物/关系后果 | 战后人物与关系不可回到战前 |
| 协作边界 | 不越权替代04/05/06/07/09 |

以下P0失败直接退回：临时外挂；角色无来源知道秘密；对手突然失智；大招无前置/交互/代价；规则只约束配角；终结没有因果主体或战后状态；将设计误报为已物理可执行或已实渲染验证。

## 专项压力测试

- T1 普通动作不误触发：摔倒后起身只补重量受力，应交05，不强造武学。
- T2 双人风格分离：谨慎近身控制者对冒险长兵爆发者，不看名字仍可区分。
- T3 世界规则战术化：谎言增加身体重量，规则须改变双方策略并对称生效。
- T4 群战：四人护送不能移动目标穿过狭窄空间，形成任务、路线和失位后果。
- T5 Boss阶段：Boss会学习重复攻击，阶段须改变方法和胜利条件。
- T6 大招非光炮化：借力型角色的终结须继承借力命题并给对手交互机会。
- T7 重赛进化：第三次交锋须让旧签名被预判、反用或改写。
- T8 原九能力保全：原目录字节不变、原Skill不依赖10、路由不强制10。
- T9 Prompt主权：完整工具包由06收口；10只给战斗事实，06缺失才兜底。
- T10 80集系列战斗稳定：至少12场关键战斗分布于E01—E80，检查认知、资源、伤势、签名与关系连续；后20集不退化为重复升级或纯大招陈列。
- T11 战斗×VFX：两套能力必须分别改变路线/支撑/距离/权限之一，并触发对手可见反应；关闭VFX后战术链应明显残缺。
- T12 高风险VFX Actor：群体飞剑、完整球体/领域或巨大显化对象至少一种，检查内外、拓扑、所有权、交互顺序和不可逆状态。
- T13 Spectacle Target：同一剧情分别指定“实体近身”与“宏观特效重型”，检查10是否真正改变空间尺度、位移、能力占区、环境与摄影危险度，而非只换形容词。
- T14 Visual Saturation：10秒高燃仙侠高潮至少让主体动作、主攻击VFX、环境响应和前/远景尺度中的多层共同运行，且全部服务一条Dominant Causal Arc。
- T15 Frame Occupancy：巨构/大招从局部建立升级到构图级占有时，检查人物比例参照、完整轮廓、画面覆盖和战术空间变化是否同步成立。
- T16 Continuous Motion Floor：主攻权切换之间不出现无因静止空窗，也不以随机挥舞、粒子和持续震镜冒充运动。

## 验收证据等级

- E2：静态结构、文件与哈希检查；
- E3：可复现的规则正反样本；
- E4：完整脚本/Prompt盲审或跨题材压力测试；
- E1：指定生成模型的真实回片或真实生产结果。

没有真实生成时不得宣称“模型一定能稳定出片”。
