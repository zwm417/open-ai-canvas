# Combat Spectacle Direction｜战斗奇观目标、视觉饱和与持续运动合同

本文件补强10已有战斗人格、对位、Combat–VFX Co-Design与阶段升级，不建立第二套战斗设计系统。

## 1. Combat Spectacle Target｜奇观强度是显式设计变量

战斗设计开始前先判断：用户究竟要的是接触与身体可读优先，还是大空间高速、特效重型、ACT爽战、宏观神战/巨构对撞。Spectacle Target至少影响：

- **Spatial Scale**：战斗主要在贴身、房间/街区、百米跨区、公里空域还是天地巨构尺度上成立；
- **Displacement Scale**：角色是否只微调站位，还是持续跨层、跨建筑、跨地貌；
- **Ability Occupancy**：能力只占局部接触点，还是改变整条路线、大片空域、地表/天空层；
- **Environment Participation**：环境只是受击反馈，还是持续成为破坏、遮挡、支撑、测速与路线变量；
- **Camera Aggression**：摄影以稳定证明为主，还是允许贴地冲刺、俯冲、甩镜、擦镜、爆点后撤等高危险参与；
- **Event Saturation**：一个主因果中允许多少并行可见层持续运行。

这些都是相对目标，不强制固定米数、镜头数或爆炸数量。用户给出的具体尺度与参考优先。

## 2. Visual Saturation Budget｜画面“满”必须有层级，不是堆满屏幕

每个阶段按需分配：

1. **Subject Action Layer**：主体身体、武器、相对位置、攻防可读；
2. **Primary Ability Layer**：主攻击/领域/VFX Actor执行当前战术职责；
3. **Persistent Secondary Layer**：上一动作留下的火、冰、雷、雾、剑群支流、残流等继续运行；
4. **Environment Response Layer**：地面、建筑、水、沙、雪、云、碎石等同步响应并改变世界；
5. **Foreground Impact Layer**：近景碎屑、剑气/浪刃擦镜、遮挡、冲击波、爆尘增强临场危险；
6. **Background Scale Layer**：远处山体、云层、战场爆点、群体/巨构持续证明尺度。

规则：
- 所有层必须属于同一主因果或已建立状态的持续后果；
- 主体动作和主攻击层永远拥有最高叙事/战术权重；
- 高潮不是六层强制全开，而是确保视觉规模不因“保持清晰”退化成空旷、局部、低压画面；
- 一旦层与层争抢主体、接触或空间解释，先减次级层，不减关键战斗事实。

## 3. Frame Occupancy Target｜大招必须改变构图占有，而不只是数值变大

高风险巨构/VFX Actor与大招设计时，10至少明确相对占有关系：

- 人物在这一镜是主要主体、尺度参照还是极小剪影；
- 能力/巨物是否需要完整轮廓进入画面；
- 它是局部覆盖、横贯画幅、占据大部分天空/地表，还是跨前中后景；
- 大招前后Frame Occupancy是否发生可读升级；
- 能力占有变大后，是否真的改变可用路线、空间权限或战斗阶段。

“人物旁边一个更大的光团”不算宏观升级；“天幕级、山岳级、覆盖战场”也不能只靠形容词，后续必须由04摄影和05环境/尺度证据证明。

## 4. Continuous Motion Floor｜持续压迫的底噪

高燃爽战中，主动作之间仍需有可消费运动：

- 未完成的武器惯性/回收；
- 防守方持续变线、落地、踏空、滑移或重组防线；
- 已建立VFX Actor继续追击/回补/收缩/传播；
- 火、冰、雷、沙尘、水雾、碎石、云层等按上一因果继续运动；
- 摄影机依据上一事件继续制动、追赶或重新释放空间。

底噪不能成为无意义Busy：没有战术/空间/物理来源的连续挥舞、随机粒子、持续震镜、全身残影都不计。

## 5. Spectacle Escalation｜奇观升级必须改变“画面结构 + 战斗结构”

阶段升级至少同时满足两类变化中的各一项：

- 战斗结构：距离、路线、支撑、资源、权限、主动权、目标或世界规则改变；
- 画面结构：空间跨度、能力占区、并行层数、Frame Occupancy、环境参与、VFX Actor拓扑或摄影参与强度改变。

只把普通攻击从10米写到100米、把粒子翻十倍、把镜头摇得更厉害，不算完整奇观升级。

## 6. Spectacle Protection Handoff

交给05/04/06时按需保护：

`Spectacle Target + Displacement Scale + Primary Ability Occupancy + Saturation Layers + Frame Occupancy Target + Continuous Motion Floor + Peak Escalation Delta`

这些是视觉规模权威事实，不是最终Prompt字段。06可以炼化表达，但不能把“特效重型宏观仙侠”压回“清楚的局部双人对打”。
