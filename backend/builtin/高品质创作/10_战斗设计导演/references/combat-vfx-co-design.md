# 战斗 × VFX 共设计与高风险语义对象合同

本文件是10的上游战斗设计方法，不替代05的动作物理/VFX实现、04的摄影证明或06的最终Prompt编译。

## 根原则｜能力先作为战术行为，再作为视觉现象

超自然能力、法器、领域、召唤物、群体飞剑、巨型显化等不能在战斗设计完成后才“加特效”。只要某能力会改变攻击范围、路线、支撑、视野、距离、资源、权限或主动权，它就属于战斗系统本身。

设计顺序优先为：

`人物战斗命题 → 战术问题 → 能力功能 → 空间占用/权限 → 对手被迫响应 → 反制/付费破局 → 状态变化 → 05物理/VFX实现 → 04观看证明 → 06前台编译`

删除VFX后若这一轮战术因果仍完全一样，说明能力可能只是装饰；世界设定本来就是纯视觉象征时例外。

## Combat–VFX Co-Design 七问

每个关键超自然能力至少回答以下问题；简单能力按需缩减，不强制填表输出：

| 变量 | 设计问题 |
|---|---|
| Tactical Function | 它真正抢什么：距离、路线、支撑、视野、武器展开、资源、权限、主动权？ |
| Trigger | 哪个身体动作、武器状态、标记、资源或世界条件使它合法发生？ |
| Occupancy | 它占据哪条攻击通道、地面区域、高度层、边界、介质或邻接关系？ |
| Pressure | 对手如果不改变行为会付出什么代价，因此被迫做什么？ |
| Counterplay | 对手怎样躲、挡、破、绕、吸收、误导、切断来源或反用？ |
| State Change | 成功、失败、被挡或近失后，距离、路线、支撑、资源、权限、环境怎样改变？ |
| Persistence | 哪些残留继续成为下一轮战斗成本，直到出现可见解决原因？ |

“火、水、雷、冰、黑雾”只是材料/属性入口，不是战术答案。同一种火可以是封路、持续消耗、视野遮蔽或推进面；同一种雷也可以是瞬时抢先、传导封区或打断权限。功能必须来自当前人物和对位。

## Ability Occupancy｜能力必须占据真实战术空间

复杂武戏优先把能力写成可比较的空间事实：

- 哪条路线被封；
- 哪个高度层变危险；
- 哪块支撑面被破坏；
- 哪个边界内外规则不同；
- 哪个攻击半径迫使对手压缩/拉开距离；
- 哪种介质连接让原本安全的位置不再安全。

占区不是“大范围特效铺满画面”。真正成立的占区必须让角色选择改变，并在下一动作被利用。

## Outcome Vocabulary｜命中、格挡、近失、击空不是同一种结果

同一能力至少根据当前重要性区分：

- **命中**：对象状态、支撑、资源、权限或身体关系真正改变；
- **格挡/偏转**：传播被改变，防守端承受代价或暴露新的线路；
- **近失**：攻击未接触主体，但迫使变线、丢支撑、暴露侧位或改变速度；
- **击空环境**：攻击继续进入世界并改变地形、掩体、建筑、介质或后续路线。

不要让四种结果都只表现为同样颜色与同样爆炸。

## High-Risk Semantic Object｜高风险语义对象

以下对象若是核心卖点，不能只给一个漂亮名称：群体飞剑/无人机、雷暴球、领域/结界、空间门、巨大法相/召唤物、复杂法器、巨构攻击、可变拓扑武器、具备独立运动的VFX实体。

后台建立最少必要定义：

1. **Identity**：它究竟是什么，和相似现象的区别；
2. **Geometry / Topology**：宽、高、厚度、纵深、边界、内部/外部、前中后部或可变拓扑；
3. **Ownership**：谁控制，谁在里面/外面，武器/能力归属是否独立；
4. **Material Identity**：材料怎样传播、变形、接触和留下残留；
5. **Motion Grammar**：整体怎样移动，内部怎样换层、分流、回补、压缩/展开或旋转；
6. **Interaction Order**：谁先接触谁，边界/球壳/实体端是否先于人物本体；
7. **Lifecycle / State**：形成、稳定、受损、转化、衰减、消散的单向状态；
8. **Anti-Interpretation**：最危险、最高概率的错误解释是什么。

高风险对象不是要求把八项全部写进最终Prompt。10只负责把不可替换的战斗事实标出来；05补物理和VFX事实，04决定需要哪些摄影证明，06按风险与字符预算编译。

## VFX Actor｜把具有独立行为的特效当作战斗Actor

当一个现象拥有自己的几何、运动、空间占用、持续状态和交互能力时，把它视为`VFX Actor`，例如三维鱼群式飞剑群、完整闭合雷暴球、法相、巨型冰兽、移动领域边界。

VFX Actor至少拥有：`Identity + Topology + Motion + Ownership + State + Interaction`。它可以参与封路、围猎、追击、阻挡、承载、抓握或碰撞，不能在关键Window退化成背景贴图、屏幕覆盖层或单纯颜色光效。

## 战斗阶段与VFX阶段必须互相改变

战斗升级时，VFX升级不以“更大、更亮、更多粒子”为充分条件。至少有一项真实变化：

- 能力第一次改变战术路线；
- 对手学会针对传播介质或触发条件反制；
- 资源/权限损耗改变可使用的能力形态；
- 地形被能力改造，旧打法失效；
- 持续状态积累到阈值，获得新终结窗口；
- VFX Actor的拓扑/所有权/边界状态发生不可逆变化。

大招必须继承这些前段事实，而不是普通攻击视觉放大。

## Protected Combat Semantics｜受保护战斗语义

交给05/04/06时，把以下高风险事实按需标成不可因压缩删除：

- 战术功能与对手被迫响应；
- 能力占区和关键路线；
- 实体/VFX Actor的所有权、内外关系和拓扑；
- 决定性接触顺序；
- 武器/能力实例与不可逆状态；
- 大招的前置、代价、反制和残留；
- 删除后会改变胜负逻辑的世界规则。

这里的“Protected”是交接优先级，不是最终Prompt字段。前台仍由06统一编译。
