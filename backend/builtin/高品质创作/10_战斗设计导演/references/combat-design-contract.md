# 战斗设计合同

本文件定义第10 Skill 的后台事实结构。按任务规模裁剪，不要求把全部字段展示给用户。

## 战斗真相

- 表面目标：角色嘴上或当下表现出来的目标。
- 真实目标：战斗真正要解决的利益、关系或身份问题。
- 胜利条件：击倒、拖延、救援、夺物、护送、试探、逃脱、公开、迫使表态等。
- 失败条件：不只“被打败”，还包括暴露秘密、失去盟友、违背底线、耗尽资源。
- 禁区：角色不能或不愿使用的手段。
- 叙事职责：这场战斗必须改变全剧哪一项状态。

双方胜利条件不同时必须保留不对称。一个想杀、一个想拖延、一个想保护时，不能按普通擂台赛设计。

## 战斗人格卡

| 字段 | 问题 |
|---|---|
| 战斗命题 | 他认为什么才算真正赢 |
| 身体事实 | 体型、伤势、年龄、耐力、惯用侧、感觉限制 |
| 运动身份 | 直线/弧线、贴身/远距、稳定/漂移、爆发/积累、刚/柔、控制/交换 |
| 首选距离 | 他最能发挥的空间关系 |
| 主动权方式 | 逼近、封线、诱导、抢先、反击、消耗、欺骗、占地 |
| 压力惯性 | 受压时本能做什么 |
| 风险偏好 | 愿意用什么交换什么 |
| 资源 | 武器、能力、体力、队友、时间、地形、情报 |
| 盲区 | 他读不懂、看不起或不愿承认什么 |
| 标志语法 | 2—4个可反复识别的动作原则 |
| 漂移禁区 | 哪些行为会破坏人物战斗身份 |
| 成长变量 | 本场或系列战斗中他学会、放弃或承担什么 |

## 战斗状态

每个阶段结束至少更新：人物位置与相对距离；支撑/失衡/受控状态；武器与能力实例、归属和可用性；伤势与疲劳；已暴露和隐藏的信息；主动权与当前目标；地形路线；关系与心理；未完成动作与下一步债务。

状态记录约束事实，不预设选择。角色可以反常，但反常必须由伤口、诱因或成长触发，并承担后果。

## 能力战术合同

超自然能力、法器、领域、召唤物或群体VFX若参与战斗，至少在关键能力上锁定：战术功能、触发、空间占用、对手被迫响应、反制、状态变化和持续成本。复杂对象再补Identity/Topology/Ownership/Interaction Order。完整字段见`combat-vfx-co-design.md`。

能力视觉形态可以调整，但如果删除它后原来的封路、逼位、支撑破坏、资源消耗或主动权变化仍完全成立，说明其战术身份不足。

## 战斗奇观合同

当用户锁定高燃/高速/特效重型/宏观神战等画面目标，额外记录`Combat Spectacle Target`：主要空间尺度、位移跨度、能力占区、环境参与、摄影危险度、高潮Frame Occupancy和Continuous Motion Floor。奇观不是装饰标签；它决定当前战斗在视觉上应当多大、多满、多持续。详细见`combat-spectacle-direction.md`。


## 对位合同

不要只写“甲克乙”，要写出：甲怎样建立优势；乙为何吃亏；乙观察到什么；乙改变什么；甲怎样二次适应；谁为破局付出什么。

真正的克制必须在动作与状态变化中被看见，而非由旁白宣布。

## 阶段成立标准

新阶段至少满足一项：旧方法失效；胜负条件改变；距离或地形规则改变；资源被授权/失去；阵营或保护对象改变；隐藏信息公开；角色跨过禁区；世界规则被正确理解或反用。

只换新招式、新颜色、新镜头或更大爆炸，不算新阶段。

## 战斗后果

至少结算两层：外部结果、人物内部变化、关系变化、世界变化、永久代价。战斗若只留下“赢家站着、输家倒下”，通常没有完成叙事职责。
