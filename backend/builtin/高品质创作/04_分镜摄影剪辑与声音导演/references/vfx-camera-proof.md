# VFX Camera Proof｜能力、拓扑、尺度与交互摄影证明

本文件扩展04已有Camera Proof，不建立VFX镜头模板。摄影复杂度仍由当前观看责任决定。

## 核心原则

摄影机拍VFX时首先问：**这一镜必须证明这个现象的哪一个战斗事实？**

常见责任：

- Origin Proof：能力从谁/什么实体产生；
- Path Proof：传播路径、转向和世界空间位置；
- Occupancy Proof：哪条路线/高度层/边界被占据；
- Scale Proof：和人物、建筑、山体、地貌的比例；
- Topology Proof：群体宽度、厚度、纵深、内外关系或完整轮廓；
- Interaction Order Proof：谁先接触谁，边界/球壳/实体端是否先于人物本体；
- State Proof：形成、稳定、受损、分裂、回收、衰减是否连续；
- Tactical Consequence Proof：对手为什么变线、支撑为什么失效、旧路线为什么不能继续。

## 摄影选择按Proof反推

- **真实瞬移/大跨度换位**：当核心是证明“人物换了位置而不是镜头吃掉距离”，可优先固定或相对稳定机位，用稳定背景/地标证明原位消失与异地出现；不是所有瞬移都必须固定机位。
- **巨大完整体/雷暴球/领域**：需要内外关系与整体轮廓时释放空间，保留比例参照；核心事实读清后可进入近景，不要求全程远景。
- **群体VFX Actor**：需要证明群体宽度、厚度、纵深、分流与回补时优先从群体外部拍；摄影钻进群体内部会丢失Topology Proof时应避免。
- **法相/巨物动作**：继续证明同一巨大Actor、攻击端、目标与距离，不因特效增强把动作主权切回本体。
- **领域/封路**：构图应同时容纳能力边界与被迫改变路线的主体，否则只看见漂亮效果但看不见战术作用。

## VFX与摄影的相对运动

摄影机运动、VFX传播、主体运动必须存在可解释的相对关系。追随VFX不等于永远跟在光效后面；有时固定机位让现象穿屏更能证明速度，有时后拉才能显示范围，有时侧移产生视差才能证明世界空间厚度。

决定性原则：摄影变化必须新增观看信息，不能与主体/VFX同时无差别拉满造成空间不可读。

## 高风险重复不是镜头重复

高风险对象可以在全局定义、关键成立镜头、交互镜头中被多次证明，但每次应该承担新的责任：第一次证明它是什么，第二次证明它怎样运动，第三次证明接触顺序/后果。不要用三个几乎相同的远景只为了重复“它很巨大”。
