# Spectacle Density Compiler｜战斗奇观、视觉饱和与画幅占有前台编译合同

本文件扩展06的Maximum Executable Semantic Density、Frontend Director Sentence v4与Protected Combat Semantics，不改变五段最终Prompt。

## 1. Spectacle Target Compiler

收到10/用户的Spectacle Target后，把抽象“高燃/宏观/特效重型”编译成最少必要的可见事实：
- 角色跨越什么空间层级；
- 主能力占据哪条路线/高度/地貌/空域；
- 环境在哪些层持续响应；
- 摄影何时贴身危险、何时释放空间证明规模；
- 高潮Frame Occupancy怎样比前段升级。

若最终Prompt只有“史诗、震撼、天幕级”，视为未编译。

## 2. Visual Saturation Compiler

高奇观时间窗允许六层中的多层并存：
`主体动作 / 主攻击VFX / 持续VFX / 环境响应 / 前景冲击 / 远景尺度`。

编译顺序仍以主因果为核心。句子可很长，只要每一Clause都新增可执行事实。字符压力下，先删：重复爆点、同义粒子形容、重复材质词；后删：次级环境层；最后才考虑主动作、主VFX、对手响应、占区和Camera Proof。

## 3. Frame Occupancy Compiler

宏观对象/大招需要至少一种可见占有关系：
- 人物缩成尺度参照而巨构完整入画；
- VFX横贯画幅、占据主要天空/地表；
- 群体/VFX Actor跨前中后景建立厚度；
- 攻击前后构图主权发生明显转移。

数字比例只有用户/可靠来源明确时使用；否则用相对画面关系。

## 4. Continuous Motion Floor Compiler

高燃连续区的Window之间，前一动作留下的武器惯性、人物防守/位移、VFX Actor内部运动、环境残流、摄影制动/追赶应自然继承。不要每个Window重新写“开始高速移动”；也不要为了“动作不停”强行给每人添加无目的挥舞。

## 5. Readability within Aggression Compiler

摄影句法可以激进：贴地共速、俯冲、主体超越摄影、甩镜再锁定、擦镜、冲击波后撤、爆点穿越等。条件是关键接触/空间关系在需要时可读，并且激进摄影由当前事件触发。不是每镜都要安全中远景证明，也不是每镜都要镜头晃动。

## 6. Spectacle Compression Failures

以下属于压缩失败：
- `SPECTACLE_SCALE_DOWNGRADE`：上游宏观战斗被压成局部人物特写/中景，关键尺度不再可读；
- `VISUAL_SATURATION_COLLAPSE`：高燃高潮只剩主体+单一光效，环境/持续层无因消失；
- `FRAME_OCCUPANCY_UNDERCOMPILED`：写“巨大/天幕级”但没有相对构图和比例参照；
- `MOTION_FLOOR_DROPOUT`：连续压迫段在主攻切换之间无因全停再重启；
- `AGGRESSION_OVERREADABILITY`：为了可读把摄影全程锁成安全侧面中景，视觉危险度低于目标；
- `AGGRESSION_UNREADABLE`：反过来摄影/VFX全量拉满导致主体、接触和攻击轴不可读。
