# 最大可执行语义密度与战斗前台保真合同

本文件补强06已有`Professional Natural Language / Semantic Weight Budget / Window Main Delta / Risk-Weighted Explicitness / Prompt Compression`，不改变智影五段最终Prompt。

## Maximum Executable Semantic Density

最终Prompt目标不是最短文本，而是在平台/工程字符预算内，最大化**互不冲突、能改变生成结果的可执行语义事实**。

区分三类密度：

1. **有效密度**：新增主体、动作、空间、材料、VFX功能、摄影、声音、状态或因果事实；优先保留。
2. **冗余密度**：同义形容、无对象技术宣称、重复成像口号、已经由参考承担的静态外观；优先删除。
3. **冲突密度**：同一执行窗口内多个主体/摄影/VFX要求争夺同一控制权，或互斥状态同时成立；必须裁决而不是继续加字。

Prompt长本身不构成失败。只有新增Clause无执行价值、引入冲突、挤压更高权重事实或越过工程门时才压缩。

## One Dominant Causal Arc per Window

`Single Main Delta`正式按**主因果链**判断，不按动词数量判断。一个Window可以高密度包含：

`起始空间/支撑 → 发力/动作启动 → 连续微动作 → 对手响应 → 接触/近失/格挡 → VFX传播/交互 → 环境反馈 → 摄影响应 → 直接结果/下一状态`

只要这些Clause共同服务同一个Dominant Causal Arc，就不是过载。只有第二个独立主体开始另一条可单独验收的完整因果链，或多个互不依赖的状态跃迁并列，才拆窗。

## Risk-Weighted Semantic Reinforcement

重复按`错误概率 × 错误代价 × 纠错困难`决定：

- 低风险：Global Authority一次定义，后续默认继承；
- 中风险：Global定义 + 状态变化处短重申；
- 高风险：允许`Global Definition → Local Execution Proof → Final Reinforcement`三层加权。

高风险示例包括核心对象内外关系、复杂拓扑、明确武器实例/脱手、决定性接触顺序、巨构尺度、显化Actor动作主权等。这里允许必要重复，不等于每镜复述完整定义。

## High-Risk Object Compiler

当10/05标记高风险语义对象，06优先保留会改变解释的最少事实：

`Identity + Geometry/Topology + Ownership + Motion/Function + Interaction Order + Current State`。

复杂对象第一次完整定义可以放在【全局设定】；时间轴只写当前形态/状态Delta和必要Proof；【全局补充/硬锁】只再次收口最高代价漂移。

## Protected Combat Semantics Preservation

10/05/04交出的以下事实默认进入压缩保护区：战术功能、能力占区、对手被迫响应、关键攻击/接触路径、VFX Actor所有权/拓扑、实体攻击端、不可逆状态、Camera Proof、终结前置/交互/代价/残留。

06拥有表达与长度主权，但**不得用更短的抽象词替代这些事实**。例如不能把“封住低线迫使对手上升，下一击利用高位通道”压成“双方特效激烈对轰”。

## Causal Bandwidth Preservation｜压缩顺序

进入字符压缩时：

1. 先删空泛形容和同义质量词；
2. 再删无职责设备/渲染/伪精确参数；
3. 合并稳定Global和参考已承担的静态信息；
4. 删除低风险重复；
5. 缩短摄影器材描述但保留Camera Proof；
6. 缩短次级VFX装饰但保留来源、路径/功能、交互、结果；
7. 最后才允许压缩受保护因果，而且必须保证因果仍唯一可读。

压缩后的Prompt若字符更少但需要模型重新猜测“谁产生、哪里传播、为什么变线、谁先接触、结果留下什么”，属于压缩失败。

## Frontend Director Sentence v4

v4仍是自然导演句，不是字段表。新Shot与延续窗保持v3镜头身份逻辑，但允许更高的因果承载：

- 新Shot首窗：`时间戳 + 镜头身份/观看责任 + 必要空间关系 + 动作启动/发力 + 连续动作与对手响应 + 接触/状态变化 + VFX/环境/声音因果 + 必要Camera Delta + 下一可见状态`
- 同一Shot延续窗：`时间戳 + 最短既有镜头锚点 + 当前主因果继续 + 仅变化的摄影/VFX/状态 + 直接结果`

不是每项机械出现。判断标准是读完一句能否直接在脑中连续看到这一Window，而不是能否数出字段。
