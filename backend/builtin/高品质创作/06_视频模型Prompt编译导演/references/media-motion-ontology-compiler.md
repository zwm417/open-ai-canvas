# 媒介 × 运动规则双轴前台编译

本文件只负责最终Prompt的媒介化表达，不改变01/02/03/04/05/10已经锁定的故事、资产、表演、摄影、动作物理、VFX和战斗设计事实。

## 一、先分两条轴

### 成像媒介轴

- 真人实拍感；
- 3D/CG/三渲二；
- 2D动画/手绘；
- 定格、拼贴、版画等材料媒介；
- 真人与动画、三维与二维、不同材料之间的混合或转换。

### 运动规则轴

- 现实身体：常规人体、武器和环境力学；
- 电影化强化：更快、更重、更远，但仍保留清楚发力、接触和后果；
- 超能力：瞬移、飞行、念力、时间、空间、元素、变形等明确权限；
- 抽象世界规则：二维化、重力改写、记忆变成实体、语言改变物理等自定义规则。

媒介不决定权限。真人可以拥有任何已建立的超能力；3D也可以完全现实克制。

## 二、跨媒介共同硬核

无论哪种组合，都优先保住：

1. 谁触发、谁行动、谁承受；
2. 起点、路径/跃迁关系、交互、结果；
3. 当前身体、服装、武器、道具与能力实例；
4. 角色知识、意图和战术代价；
5. 环境与其他角色的同步反馈；
6. 下一时间窗从最新状态继续。

超能力不是省略因果的许可证。若能力是瞬移，至少确定：触发方式、出发处如何失去主体、空间关系如何断开、抵达位置与姿态、动量是否继承、环境是否有延迟反馈、使用后留下什么限制。

## 三、媒介表达

### 真人实拍感

- 保持真人皮肤、肌肉张力、呼吸、衣料、头发、道具重量和现场光影；
- 强动作先给可读的身体起因或能力触发，再给空间结果；
- 瞬移、飞行、能量化等可以完全成立，但抵达后的支撑、视线、呼吸、衣料/碎屑、周围人物反应要与新状态一致；
- 不默认使用动画停帧、速度线、0帧前摇、拉伸变形、重复残影分身；用户或世界规则明确要求时才用，并将其写成真人画面中的具体视觉机制；
- VFX应附着于身体、道具、环境或空间事件，不替代真人主体。

### 3D/CG

- 先确定写实CG、风格化3D、三渲二或其他渲染家族，不默认UE5；
- 允许更强轮廓、动作弧线、预备—爆发对比和控制性形变，但程度由题材决定；
- 材料形变、布料、毛发、表面能量与环境破坏要服务力和能力，不作独立展示；
- 写实3D仍要保留重量、关节范围、重心和接触闭合；风格化3D才按授权提高夸张度。

### 2D动画

- 优先姿态轮廓、线条方向、关键Pose对比、Smear/残像、冲击构图与余势Pose；
- 只有需要读到实体接触时才安排冲击停顿，不能每次命中都机械Freeze；
- 背景线、速度线、色块或画面变形必须表达路径、压力、情绪或规则变化，不作常驻装饰；
- 人物战斗人格要从姿态、距离、节奏和选择中持续可辨认。

### 混合媒介与维度转换

- 明确转换触发者、转换边界、传播顺序和完成条件；
- 转换前后的角色身份、位置、朝向、武器归属、伤势与动量默认连续；
- “3D转2D”不能只换滤镜：体积、遮挡、阴影、线条、表面和运动自由度至少有两项真正改变；
- 保留一个稳定参照物或未转换对象，证明转换发生在世界中而不是全片风格突然漂移；
- 转换必须改变行动、路线、能力或风险，否则只是视觉皮肤。

## 四、典型组合

| 组合 | 前台重点 |
|---|---|
| 真人 + 现实身体 | 发力、重心、接触、受力、呼吸、短反应、环境后果 |
| 真人 + 超能力 | 真人身体/表演锚点 + 清楚触发 + 能力运动身份 + 抵达/命中后的实体与环境状态 |
| 3D + 现实身体 | 写实关节与重量 + 材料/布料/表面反馈，克制夸张 |
| 3D + 超能力 | 战斗轮廓和动作弧线 + 属性材料/空间身份 + 对手交互 + 余波 |
| 2D + 现实身体 | 可读Pose、路径和接触，有限Smear，不让风格遮掉动作因果 |
| 2D + 超能力 | Pose/线条/构图与能力规则同步变化，避免只有换色和特效铺屏 |
| 真人 ↔ 2D/3D | 转换触发、边界、身份/动量连续、稳定参照、战术后果 |

## 五、Shot与Window

- 新Shot首窗：先建立景别、主体关系和最短有效摄影运动；
- 同一Shot延续窗：用一个最短的既有镜头身份锚点确认摄影连续，并保留观看尺度/关系与摄影状态的最小必要信息；立即写动作/表演，仅在摄影真正响应时写Camera Delta，不把“同一镜头继续”机械复制成固定口令；
- 新时间窗不自动等于切镜；
- 一窗围绕一个运动或情绪目标，可包含服务该目标的连续微动作；不要把完整连招拆成逐帧动作清单；
- 10秒、30秒或更长时长只改变容量，不强制平均镜数。

## 六、冲突裁决

1. 用户明确世界规则与媒介组合最高；
2. 参考图控制外观和媒介，不自动控制运动权限；
3. 10锁定的战斗设计、05锁定的动作/VFX因果、04锁定的观看责任进入06后不得互相覆盖；
4. 若媒介惯例与已锁超能力冲突，保留超能力，改写它在该媒介中的可见证据；
5. 若夸张会破坏真人自然度，先保留能力结果，再减少无授权的动画中间态，而不是删能力；
6. 未经真实回片A/B，不把某种句法宣称为所有模型的稳定定律。
