# Spectacle VFX Density Execution｜奇观尺度、画面饱和与持续运动执行合同

本文件补强05已有FAST/PRESSURE/IMPACT、VFX Action Fusion、Tactical Function Preservation、VFX Actor与物理后果，不建立平行特效系统。

## Spectacle Scale Preservation

上游已经锁定宏观/特效重型目标时，05优先把“规模”翻译成可见相对关系，而不是伪精确数字：

- 主体相对场景/巨构的比例；
- 攻击在横向、纵深、高度层占据多少空间；
- 位移是否跨越足够的地标/建筑/云层/地貌层级；
- 环境响应是否扩展到相应尺度；
- VFX Actor是否保持完整轮廓、世界厚度与内部运动。

尺度不允许只靠“史诗级、百米级、天幕级”词汇存在。

## Multi-Layer Event Stack

同一Dominant Causal Arc可同时执行：

`Subject Action → Primary VFX → Persistent Secondary VFX → Environment Response → Foreground Impact → Background Scale`

执行优先级：
1. 实体动作/攻击端/接触；
2. 主VFX战术功能；
3. 对手响应与空间变化；
4. 环境与持续层；
5. 前景/远景增强。

当画面拥挤时，从5向4回收，不从1—3回收。爆光、烟尘、粒子不得遮没决定性接触。

## Environment as Spectacle Multiplier

环境不只“被打坏”，还负责扩大奇观：
- 地面裂纹/水线/沙墙/雪浪沿攻击和位移方向扩展；
- 建筑、山体、云层、水面、烟尘提供前中后景尺度参照；
- 已破坏区域持续影响路线与视觉层次；
- 主体远离镜头时，环境仍证明速度和力量没有缩水。

## Persistent Motion Layer

已建立的雷、火、水、冰、黑雾、剑群支流、碎石雨、云层扰动等只要生命周期未结束，就继续运动；下一主动作不需要重新“点亮”它们。持续层可以衰减、转化、被吸收/冻结/吹散，但必须有可见原因。

## Peak Frame Occupancy

大招/巨构峰值若上游要求构图级占有，05必须让能力本体、环境响应和尺度参照共同支持它。峰值不等于白闪填屏；至少一次仍能读出Owner/攻击端/VFX Actor边界或传播方向与目标关系。
