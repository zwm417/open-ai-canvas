# 战术功能保真、VFX Actor与结果分型执行合同

本文件补强05已有的`VFX Action Fusion / Phenomenon Function Proof / Material Identity / Consequence Continuity`，不建立平行VFX系统。

## Tactical Function Preservation Gate

若上游或当前任务已经明确某能力承担封路、逼迫变线、破坏支撑、建立推进面、限制自由度、改变距离/主动权等战术职责，05在把它实体化时必须保住该职责。

执行闭环：

`战术职责 → 身体/武器/世界触发 → VFX空间行为 → 对手可见响应 → 接触/近失/格挡/击空 → 材料与环境后果 → 下一战术状态`

失败例：写“雷电封路”，画面只有漂亮落雷但对手仍沿原路线不受影响；写“冰封压制”，只有蓝色覆层但关节、护体能量、支撑或可用动作完全不变。

## High-Risk Semantic Object Execution

核心复杂对象第一次成立时，根据风险选择最少必要的可见事实：

- 外轮廓/内部关系；
- 真实世界厚度与透视；
- Owner/控制者与对象中心/边界关系；
- 父对象Anchor；
- 内部流动或群体换层；
- 接触顺序；
- 状态从形成到稳定/受损/消散的连续过程。

对象一旦成立，后续只写当前Delta；但内外关系、所有权、拓扑和不可逆损伤必须持续，直到可见改变。

## VFX Actor Execution

具有独立运动和空间行为的VFX Actor不能只按“粒子特效”处理。至少检查：

`Actor实例 → Topology → 世界位置 → 整体运动 → 内部运动 → 交互边界 → 当前状态`。

群体飞剑可有前部、中部、尾部、上下厚度和前后纵深；群体转向时前端先改向、中段随动、尾部延迟追随。雷暴球若定义为完整闭合球体，球壳与内部体积必须共同移动，中心人物不能无因漂到表面。这里只描述方法，不把任何示例尺寸变成通用硬规则。

## Outcome Differentiation

关键能力根据结果选择不同反馈链：

- 命中：接触/传播到目标 → 局部状态改变 → 力/能量扩散 → 支撑/资源/身体或环境结果；
- 格挡：边界或实体拦截 → 传播偏折/耗散/压缩 → 防守端付出代价或暴露新线；
- 近失：不命中主体 → 掠过造成气流/热/碎屑/空间压力 → 对手被迫改线/失位；
- 击空：攻击继续进入环境 → 形成新的破坏/介质/路线事实 → 后续继续承担成本。

禁止用同一种大爆炸覆盖四种结果。

## VFX–Lighting Integration

高亮能力若是主要光源，按事件需要让光真正进入世界：先照亮发射端/武器，再随传播扫亮人物边缘、烟尘/水雾/碎屑与附近表面；能量离开或衰减后，环境照度按原有光源关系恢复。局部染光、反射、阴影、体积散射只在它们能证明空间/材料/强度时出现，不为“高级感”全量叠加。

## Tactical Persistence

VFX造成的后果若改变战术，必须比纯视觉残留拥有更高优先级。例如：

- 火仍在燃烧，因此通道继续不可用；
- 冰层仍限制关节/支撑，因此动作语法继续改变；
- 地面被犁开，因此下一次落点/追击路线改变；
- 武器脱手，因此后续不能继续使用同一双持语法；
- 领域边界破损，因此权限/覆盖区改变。

只保留烧痕/裂纹贴图、但战术完全恢复，不能算后果连续。
