# 电商视觉创作 (ecom-details-image)

智影工业化电商视觉创作体系。基于产品实拍参考图、品牌规范与品类卖点，自动在【智影生图工作台】或【智影无限画布】上构建结构化生图任务。

## 核心特性

- **多模态参考图感知 (`canvas_inspect_image`)** — 基于输入产品实拍图，高保真提取材质细节、颜色代码 (HEX) 与形态特征
- **电商 7 槽位标准套图** — 主图白底、卖点场景、细节微距、功能拆解、规格尺寸、包装配件、竞品对比
- **零外部 API 泄露** — 100% 走智影统一媒体工作台管线，杜绝任何本地 API Key 配置风险
- **原生画幅对齐** — 自动适配 1:1 电商方形、3:4 小红书种草、9:16 竖屏及 16:9 横幅

## 工作台使用方式

1. **生图工作台**：选择对应电商技能卡片，输入产品特征与卖点，一键生成标准化提示词并执行。
2. **无限画布**：通过 Agent 对话触发，自动生成结构化策划案与生图节点，实现多图流式编排。
