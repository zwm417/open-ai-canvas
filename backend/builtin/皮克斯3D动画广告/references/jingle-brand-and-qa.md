## 广告歌 brief

先锁定：品牌标准读音、核心卖点、目标情绪、速度范围、拍号、调性、配器、演唱者年龄感/音色、语言、是否需要口播版和纯音乐版。

广告歌的核心不是“押韵越多越好”，而是品牌名、卖点和行动在一次播放后仍可复述。品牌名第一次出现不应过晚；具体位置由叙事决定，但必须落在清晰、无遮挡的声音区域。

## 歌词写作

1. 写事实版：只保留已核验品牌名、产品名、主要卖点和 CTA。
2. 写口语版：让角色能自然说出或唱出，删除说明书句式。
3. 写节拍版：标注每句拍数、重音、延音、休止和押韵位置。
4. 写演唱版：处理连读、难发音辅音、品牌名重音和呼吸点。
5. 写字幕版：保持事实一致，但可按阅读节奏重新断句。

禁止项：无法证实的第一/唯一/最好、保证效果、虚假稀缺、假评价、仿冒歌词、未经授权旋律和刻意模仿具体歌手声线。

建议结构：

```text
[Hook] 角色问题或拟声记忆点
[Brand] 品牌名落强拍
[Benefit] 一个真实卖点转成可见结果
[Payoff] 角色回报或反转
[Tag] 品牌名 + Slogan/CTA
```

## 声音生产

- 分别生成主唱/角色唱段、器乐、旁白/对白、重点音效和环境声，以便独立调整。
- 先用临时节拍轨验证镜头时长，画面锁定后再制作最终音乐，避免镜头和歌互相漂移。
- 记录每句歌词的开始、结束、重音和口型镜头；口型要求高时减少长句并给角色正面稳定镜头。
- 检查品牌读音至少两遍：独听人声和混音后听。错误读音必须重做，不使用字幕掩盖。
- 最终混音保持对白/歌词优先，重点音效短促清楚，BGM 不遮挡品牌名；输出前检查峰值和整体响度。

## Logo 与 End Frame

- 使用正式 Logo 的源文件、最小尺寸、留白和背景对比规则。
- 没有 Logo 时，先给原创标志方向与适用性说明，确认后再作为本片临时/正式版本使用。
- End Frame 层级：产品 Hero → Logo/品牌名 → Slogan/CTA → 价格/法务。
- 片尾动作应呼应故事或广告歌，而不是添加无关粒子特效。
- 精确文字使用后期矢量/文本渲染；逐字核对品牌名、网址、价格、日期和声明。

## 七层验收

任一阻断项失败都不能以平均分通过：

1. 品牌事实：所有声明、产品状态和 CTA 有依据。
2. 原创合规：没有可识别复制角色、场景、Logo、故事、旋律或声音。
3. 角色连续性：身份、服装、比例、左右和职业证据稳定。
4. 产品连续性：包装、材质、颜色、Logo 位置、比例和交互准确。
5. 剧作/歌词：产品改变结果，Hook 兑现，品牌名清楚，歌词可唱可懂。
6. 视听：无闪烁、穿模、融化、跳轴、字幕遮挡、口型明显错位或音乐接缝。
7. 技术：最终 MP4 可解码，时长符合 Agent 自动选定或用户明确指定的 15–90 秒具体值，规格、音轨、响度和文件大小正确。

验收报告逐层给出 PASS/FAIL、证据文件、时间码、阻断级别和返工单元。完成声明必须指向真实最终文件，而不是生成任务状态。
