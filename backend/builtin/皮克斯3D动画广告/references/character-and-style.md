## 风格转换

把“皮克斯式”转换为可执行且原创的属性组合，不在生成提示词中依赖品牌名：

- 造型：清晰剪影、圆润但有职业辨识度的比例、适度头身夸张、手部可读。
- 表演：眼神先行、眉眼口型协同、清晰预备动作、主动作、反应和停顿。
- 材质：皮肤次表面散射、织物细纹、金属/塑料受控高光、避免蜡像与过度光滑。
- 灯光：明确主光、柔和补光、轮廓光和环境色；品牌色作为动机光或场景线索。
- 摄影：低机位英雄镜、近景反应、适度景深、动机明确的推拉摇移。
- 叙事：普通职业角色遭遇可理解问题，产品改变选择或结果，结尾回到品牌记忆点。

不同方向至少改变三项：角色比例、材质倾向、色彩体系、场景年代、镜头语言或喜剧节奏。不得只是换颜色。

## 角色圣经

每个角色建立稳定字段：

```json
{
  "id": "char_hero_01",
  "role": "主角",
  "occupation": "职业",
  "ageRead": "年龄感",
  "genderPresentation": "跨镜不可漂移的性别呈现",
  "silhouette": "头身与轮廓",
  "faceFingerprint": "脸型、眼距、瞳色、眉形、鼻型、嘴型、耳朵",
  "hair": "发型、颜色、发际线",
  "body": "身高感、头身比、肩宽、体型、四肢比例",
  "wardrobe": "职业服装、颜色、材质、鞋",
  "accessories": "道具与佩戴侧、主用手、产品持有手",
  "personality": "性格与默认姿态",
  "performanceLimits": ["不做的表情或动作"],
  "immutable": ["跨镜不可改变项"]
}
```

职业可读性至少由两个视觉证据支持，例如服装结构 + 专属道具，或动作习惯 + 工作场景。避免用刻板身份特征替代职业设计。

## 立绘生成顺序

1. 轮廓探索：同一 brief 生成少量差异方向，先看剪影、职业与品牌匹配；探索图不得直接进入剧情镜头。
2. 唯一身份主图：选定一个方向后，独立生成单角色、中性站姿、干净背景的完整主图。禁止三视图、拼版、宫格、编号和表情表。检查 `genderPresentation`、脸部指纹、发型、头身比、服装和左右手后锁定。
3. 脸部转面：连接已批准身份主图并使用同一模型，分别得到正面、左右 3/4 和侧面脸部证据。
4. 全身转面：连接同一身份主图并使用同一模型，生成正面、侧面、背面和 3/4 全身证据。
5. 表情表：连接同一身份主图并使用同一模型，生成中性、喜悦、疑惑、挫折、惊讶、决心和品牌高潮。
6. 口型：至少覆盖闭口、开口、圆唇、宽唇和齿音状态。
7. 姿态：站、走、跑、拿取、展示、使用产品与结束 Pose。
8. 尺寸表：角色与产品、主要道具、场景物的比例。
9. 组合测试：角色持有产品并完成关键动作，确认手部和产品不漂移。

转面与表情拼版只作为审核材料。剧情镜头身份参考始终使用唯一身份主图，不把拼版作为主要生成输入。

## 连续性审核

- 面部：眼距、瞳色、眉形、鼻型、嘴角和耳朵一致。
- 头发：轮廓、分缝、长度、发色和发饰一致。
- 服装：领口、袖长、图案、纽扣、口袋、鞋和材质一致。
- 身体：头身比、肩宽、手掌、腿长和身高关系一致。
- 道具：形状、颜色、佩戴侧、持有手和状态一致。
- 产品：比例、包装、Logo 位置、开合状态和接触方式一致。

任何身份锚点 FAIL 都阻断批量分镜。审美评分不能覆盖身份错误。
