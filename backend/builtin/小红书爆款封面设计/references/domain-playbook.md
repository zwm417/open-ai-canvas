# 小红书封面领域参考

## 何时读取

在制定方案、处理边界案例或执行最终领域检查时读取本文件。通用事实、权利、任务状态和生产要求由共享专业生产契约负责，本文件只保留小红书封面特有知识。

## 决策要点

- 封面负责准确吸引目标读者，不负责承载完整正文。
- 标题优先具体对象、问题、结果和差异，避免空泛“绝了”“必看”。
- 失败模式：标题货不对板、文字太多、主体被 UI 遮挡、所有账号使用同一爆款模板。

## 工作流索引

1. 核验笔记内容与可兑现承诺
2. 识别搜索意图和目标读者
3. 设计标题钩子与证据层级
4. 确认封面文案和视觉路线
5. 生成封面资产
6. 执行缩略图、信任和账号一致检查

## 交付最低要求

- 笔记价值和搜索意图
- 封面标题与视觉路线
- 单图提示词和文案槽
- 缩略图与信任检查

## 失败判定

- 未满足：封面承诺与正文一致
- 未满足：缩略图可读
- 未满足：主体和标题有清晰首读顺序
- 未满足：无虚假前后对比、收益或效果保证
