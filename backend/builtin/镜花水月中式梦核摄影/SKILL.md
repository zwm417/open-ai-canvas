# 镜花水月 · 中式梦核摄影提示词与画布协同

把一句画面想法或参考图编译成稳定、高级的中式梦核美学作品。
核心美学灵魂：**主体仍然可信写实，空间与光影却在光学或时间上发生轻微、诗意的失序。**

---

## 工业化执行标准 (双模执行管线)

### 模式一：画布 Agent 执行管线 (Canvas Agent Automation)
1. **画布感知与多模态审图 (`canvas_get_state` + `canvas_inspect_image`)**：
   - 启动时调用 `canvas_get_state` 读取当前画布节点与参考图资产。
   - 若画布上已有用户上传的人物、道具或场景图片节点，**必须调用 `canvas_inspect_image(nodeId)` 细致观察真实画面**：
     1. 人物面部五官、发型与神态（保持真实可信，拒绝蜡像感）；
     2. 服饰质感与材质（丝绸、麻、纱的半透明与垂坠感）；
     3. 背景光线与色彩倾向（提取冷暖明暗对比与青绿灰色系）。
   - 严禁凭空盲猜参考图外观，必须将提取到的真实特征融入提示词。

2. **画布实体落位与拓扑连线 (`canvas_apply_ops`)**：
   - **摄影方案节点**：调用 `canvas_apply_ops` 创建 `markdown` 节点（`nodeType: "markdown"`, `title: "镜花水月·中式梦核摄影方案"`），记录：
     - 光学异常机制（镜面重影、雾气凝结水珠、薄纱遮蔽反光、双重时空倒影）；
     - 色彩角色配置（暗青黑阴影、象牙白花、冷月银光、冷暖微反差）；
     - 核心 ImageGen 中文提示词与 Midjourney 英文提示词。
   - **生图草稿节点**：调用 `canvas_apply_ops` 创建 `image` 草稿节点（`nodeType: "image"`, `title: "中式梦核-摄影成片"`）。
   - **建立连线**：若有参考图片节点，在 `canvas_apply_ops` 中使用 `connect_nodes` 建立从源参考图至目标 `image` 节点的连线依赖。

3. **模型协商与原生出图 (`model_list` + `generate_media`)**：
   - 当用户明确要求“生图、生成、出图”时：
     1. 调用 `model_list(mode="image", referenceNodeIds=[...])` 查询当前生效的图像生成模型（如 `gpt-image-2.5` 4K 质量档位）；
     2. 经用户授权确认后，调用 `generate_media` 提交生成任务：
        - `mode`: `"image"`
        - `nodeId`: 目标 `image` 节点 ID
        - `title`: 节点名称
        - `prompt`: 完整中文/英文提示词（若有参考图，在描述中精准使用 `@图片1` 绑定）
        - `referenceNodeIds`: 引用的画布图片节点 ID
        - `size`: 默认 `16:9`（宽幅电影感）或用户指定的 `9:16`、`3:4`
     3. 通过 `task_get` 核验任务状态并将结果回写画布节点。

4. **动线美学排版 (`canvas_arrange_nodes`)**：
   - 节点创建与出图后，调用 `canvas_arrange_nodes(mode="flow")` 完成画布自左向右的工整排版。

### 模式二：生图/生视频工作台直达态 (Workbench Direct Mode)
- **开箱即用提示词卡片**：直接提取下方经过精细调优的 Midjourney V8.2 与 ImageGen / GPT-Image-2.5 提示词；
- **参数预设**：默认 `16:9`（宽幅电影感摄影）或肖像 `3:4`，采样步数与质量建议设定为高质量/4K档位；
- **推荐模型**：优先选用 `gpt-image-2.5` 或 `midjourney-v8.2`。

## 核心美学体系与写作流程

先读取 [references/style-dna.md](references/style-dna.md)，确定本次保留的色彩角色、实物锚点与异常机制。

### 1. 元素与异常机制设计
- 从输入提取：主体、一个动作、镜头景别、视线、位置、前中后景、主异常。
- 从 [references/scene-engine.md](references/scene-engine.md) 选择或设计一个主异常：
  - **镜面残影**：铜镜或水面倒影与主体动作产生微小时间差；
  - **湿玻璃隔断**：凝结的水珠折射局部面容，产生流动的虚实光斑；
  - **织物微动**：轻纱在静止空气中轻微悬浮，打破物理常态；
  - **动作幅度可以很大，但脸、手或一个关键物体必须清晰可读**。

### 2. 默认提示词双版本输出
1. **ImageGen｜原生中文版**：
   - 用可执行的空间与成像描述代替形容词堆叠（如：`电影画幅16:9，浅景深特写。年轻女子侧脸隐于潮湿雾气玻璃后，几缕湿发贴于额角，眼神清冷凝视远方。水珠在玻璃表面缓慢滑落折射微光，背景为深暗青色水墨竹影，白色山茶花在前景微微虚焦。高对比度冷调侧逆光，微颗粒胶片质感。`）
2. **Midjourney｜英文版**：
   - 包含针对性 `--no`，保留最小风格骨架，补足色彩面积关系、材质、光线方向、虚实分层与异常运动，收尾添加 `--v 8.2`。

## 交付前质量检查

- **保留焦点**：避免全图糊化、蜡像皮肤、霓虹紫、鲜红宫殿或恐怖妆容；
- **色彩克制**：主色调为冷青、玄黑、象牙白与清冷银灰，严禁高饱和杂色；
- **零本地污染红线**：所有数据与生成操作 100% 在系统画布节点流转，不运行任何本地 CLI 脚本。
