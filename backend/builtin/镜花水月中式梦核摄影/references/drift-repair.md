# 生成跑偏时如何修复

先看用户实际输出，按构图、材质、色彩、光线、异常、参考设置分别记录。以下是修复假设，不是已证明的参数因果；图像变动不只取决于文字。

| 实际偏差 | 优先修改 | 避免 |
| --- | --- | --- |
| 美妆广告、面孔居中发亮 | 明确偏心位置、暗室低填充与未修饰肌理；压缩 glamour 类措辞 | 靠丑化脸制造梦核 |
| 全图模糊 | 指定一只眼/一颗水滴为清晰层；只让前景或反射层拖影 | 同时追加 blur、haze、fog、ghosting |
| 油画或塑料渲染 | 写 photographic still、真实丝纤维和自然肤色；排除 brushstrokes、CGI gloss | 把大师、史诗、仙气继续堆高 |
| 整张紫红或红衣占满 | 写深青近黑为大场、朱红只是窄条透光色、冷白仅窗与花 | 仅增加 low saturation，导致全灰 |
| 跑步像静态回头 | 明确身体前行方向、肩背扭转、手臂摆动和同向背景拖影 | 只增加 dynamic、unhinged |
| 镜中变两个真人 | 指定单一真人与低对比反射所在表面 | 加双重曝光到所有主体层 |
| 场景总被参考近脸占满 | 写新的景别/环境占比；核对 Attach 是否过度携带原构图 | 未经用户同意删除身份参考或归咎情绪版 |
| 无板版仍像有板版 | 检查网页 Personalization 是否真的关闭、图片参考是否保持相同 | 以两张长得像断言情绪版无效 |
| 无板版不及原系列 | 补足色光、空间、材质、异常；保持参考图，逐项对照 | 承诺单靠文字一定等效 |

提供修订后的同场景双 MJ 和 ImageGen，简述主要改动。只有用户要求实测时才调用生成工具；MJ 操作由用户完成或使用确实可用且已授权的工具。记录成功图对应的实际板代码/参考/参数；缺项保留未知，不反向编造。
