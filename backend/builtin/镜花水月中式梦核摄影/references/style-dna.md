# 风格 DNA 与证据边界

## 视觉主张

清醒、克制的现实锚点，被像旧记忆一样摇晃的房间包围。梦感主要来自观看介质与空间关系，不来自神仙装饰、疯癫表情或大量超自然物件。

## 必须保留的关系

| 维度 | 风格规则 | 可变化部分 |
| --- | --- | --- |
| 色彩 | 深青绿近黑占主场；冷青白用于窗与花；暗朱红小面积；人物肤色保有温度 | 色彩具体数值和物件分配，不要求每张都有红衣 |
| 明暗 | 暗室低填充、局部明亮冷窗，压低中间调但留暗部层次 | 窗方向可随新场景调整，不能所有平面一起提亮 |
| 构图 | 偏心锚点与有意义的暗空间；遮挡层、焦点层、背景层有距离 | 景别、视角、锚点是人还是物 |
| 成像 | 写真感连续明暗、真实皮肤/丝绸/木材/玻璃、浅景深、细颗粒 | 慢门、折射、倒影、雾玻璃等选择其一主导 |
| 失序 | 一个主异常与物理载体绑定，其他效果降为背景 | 时间错位、影子方向、涟漪、运动拖影 |
| 情绪 | 美、忧郁、疏离、微妙不安；表情通常收敛 | 动作可以静止或奔跑，不能把收敛等同全员闭眼 |

低饱和不是全灰；强明暗不是纯黑糊死；梦幻不是均匀模糊。蓝紫只允许作为微弱阴影融合，不替代主导的深青近黑。

## 人像预设，不是主体限制

当用户只说“延续原系列的人像”时，可沿用成年东亚女性、松挽黑发与拂面细发、珍珠垂坠耳饰、暗朱红薄丝衣、自然温暖肤色与克制目光。具体面孔一致需实际身份参考，Style reference 本身不能证明身份锁定。

用户指定男性、动物、器物或空镜时，迁移的是色光、层次、材质和失序机制，不把女性面孔和衣饰粘到新主体上。空镜的现实锚点可以是一只花瓶口、一颗水滴、一片清晰花瓣。

## 证据与来源

本 Skill 源于用户提供的七张竖幅结果及其后续横幅改图，另有最初一张母图。用户说明实际流程为：参考图构建 MJ 情绪版，然后结合提示词、情绪版、Attach to prompt 和 Style reference 生成。未提供情绪版真实代码、完整历史参数或每个角色槽的具体资产分配。

| 源画面 | 可见锚点与机制 | 不应从文件名推断 |
| --- | --- | --- |
| 白花遮面近景 | 右侧半张脸、大块深暗、近镜白花与玻璃 | 不能认为整张脸完整展示 |
| 斜侧人像 | 右侧人物、左侧较淡侧影、横向光学残影 | 不把残影当作第二个真人 |
| 俯角水盆 | 上部人物、下部黑色水盆涟漪、反光 | 不宣称精确历史器物品种 |
| 雾玻璃手掌 | 前方手掌和凝结水痕、后方柔焦脸 | 不擅自变成刀划血字 |
| 朱纱掠面 | 红色斜向半透明带、人物眼睛、窗与白花 | 文件名写全身但实际是近距离人像 |
| 梦中母图 | 下部人脸、上部影像、右侧白花冷窗、波纹 | 叠影是人还是反射并不完全确定 |
| 长廊回身 | 回望人物、左壁影子、右窗、流动衣料 | 文件名写远景但实际人物仍占显著面积 |

“真实摄影”“中画幅胶片”在此是生成目标及成像类比，不是实拍来源证明。朝代、花种、镜头型号未被照片可靠确定；如选明式窗格或梨花，注明为本次创作补充。16:9 图是后续生成式改图，不应标成原始 MJ 横幅参数验证。

Skill 不携带用户高清图、私人情绪版访问权或可复用的隐藏风格代码。缺少这些资料时仍可写提示词，不能保证逐像素复刻或无情绪版同等命中率。
