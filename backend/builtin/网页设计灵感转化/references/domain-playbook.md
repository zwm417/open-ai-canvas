# 网页视觉灵感转化领域参考

## 何时读取

在制定方案、处理边界案例或执行最终领域检查时读取本文件。通用事实、权利、任务状态和生产要求由共享专业生产契约负责，本文件只保留网页视觉灵感转化特有知识。

## 决策要点

- 分析顺序：内容目标 → 信息架构 → 网格 → 视觉层级 → 色彩/字体角色 → 组件 → 动效。
- 原创转化至少改变品牌、内容架构、视觉母题和组件表达中的多个层面。
- 失败模式：只换 Logo、照抄文案、复制独特插画、把截图当模板直接描摹。

## 工作流索引

1. 抓取并记录参考来源
2. 拆解布局、层级和视觉机制
3. 区分通用原则与受保护表达
4. 建立原创转化和差异化计划
5. 确认新设计方向
6. 逐资产生成并检查相似风险

## 交付最低要求

- 来源与参考分析
- 可迁移原则/不可复制清单
- 原创转化方案
- 逐资产提示词和相似性检查

## 失败判定

- 未满足：新方案服务用户自己的内容
- 未满足：没有复制 Logo、文案或独特资产
- 未满足：差异不仅是换颜色
- 未满足：来源与推断分开记录
