# 室内设计与空间可视化领域参考

## 何时读取

在制定方案、处理边界案例或执行最终领域检查时读取本文件。通用事实、权利、任务状态和生产要求由共享专业生产契约负责，本文件只保留室内设计与空间可视化特有知识。

## 决策要点

- 设计优先级：安全和结构 → 功能与动线 → 尺度与收纳 → 采光照明 → 材质软装。
- 没有精确尺寸时用“概念方案”标识，不输出施工级结论。
- 失败模式：改变窗户、家具堵门、灯光无来源、不同视角像不同房间。

## 工作流索引

1. 核验现状与不可变条件
2. 建立功能与动线需求
3. 形成布局和尺度方案
4. 锁定材质、灯光与软装
5. 确认设计方向和实施边界
6. 逐视角生成效果图
7. 检查空间连续与可实施性

## 交付最低要求

- 现状与约束清单
- 功能布局与设计理由
- 材质灯光软装锁
- 逐视角提示词和可实施性说明

## 失败判定

- 未满足：动线和尺度合理
- 未满足：门窗与结构位置不漂移
- 未满足：材料在多视角连续
- 未满足：效果图明确标注非施工图
