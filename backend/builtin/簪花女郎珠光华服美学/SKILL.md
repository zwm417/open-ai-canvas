# 簪花女郎 · 珠光华服美学导演系统

将用户的简短人物灵感或参考图，编译为华美绝伦、温润典雅的“簪花女郎·珠光华服”东方视觉大片。
以牡丹/玉兰花冠为发髻核心，融入金线织锦缎、半透明轻纱披帛与微量珠光漫射晕染，在智影画布上实现从多模态感知、方案落位到原生图像生成的全流程闭环。

---

## 工业化执行标准 (双模执行管线)

### 模式一：画布 Agent 执行管线 (Canvas Agent Automation)
1. **画布感知与多模态审图 (`canvas_get_state` + `canvas_inspect_image`)**：
   - 启动时调用 `canvas_get_state` 读取当前画布节点、已有资产与 `snapshotHash`。
   - 若画布上已有用户上传的古风女子、汉服、花饰或首饰图片节点，**必须调用 `canvas_inspect_image(nodeId)` 观察真实画面**：
     1. **面容神态与妆容**：眼眸清澈与眼神光、珊瑚色自然闭合唇彩、面部自然骨骼阴影（拒绝假白塑料感）；
     2. **发髻与簪花结构**：高耸宫廷发髻、牡丹与玉兰花冠的固定受力点、垂挂于耳际的金丝步摇与珍珠流苏；
     3. **面料分层与珠光光影**：重磅缎面织锦的厚重感、欧根纱披帛的半透视与飘逸感、金线反射与局部微光晕。
   - 提取到的真实视觉事实准确注入提示词中，杜绝凭空臆造。

2. **画布实体落位与拓扑连线 (`canvas_apply_ops`)**：
   - **美学方案节点**：调用 `canvas_apply_ops` 创建 `markdown` 节点（`nodeType: "markdown"`, `title: "簪花女郎·珠光华服美学方案"`）：
     - 记录构图母题（参见 [`references/visual-grammar.md`](references/visual-grammar.md) 与 [`references/composition-presets.md`](references/composition-presets.md)）；
     - 记录光线地图、面料分级（[`references/lighting-material-grade.md`](references/lighting-material-grade.md)）与色彩主副配置；
     - 输出 ImageGen 中文原生提示词与 Midjourney V8.2 提示词及负面漂移约束。
   - **生图资产卡**：调用 `canvas_apply_ops` 创建 `image` 草稿节点（`nodeType: "image"`, `title: "簪花女郎-肖像画面"`）。
   - **建立连线**：若有参考图片节点，在 `canvas_apply_ops` 中使用 `connect_nodes` 建立从源参考图至目标 `image` 节点的连线依赖。

3. **模型协商与原生媒体生成 (`model_list` + `generate_media`)**：
   - 当用户确认需要出图时：
     1. 调用 `model_list(mode="image", referenceNodeIds=[...])` 查询当前生效的高画质生图模型（如 `gpt-image-2.5` 4K 或相关特惠渠道）；
     2. 调用 `generate_media` 发起生成审批与任务提交：
        - `mode`: `"image"`
        - `nodeId`: 目标 `image` 节点 ID
        - `title`: 节点名称（如 `簪花仕女-珠光华服`）
        - `prompt`: 完整提示词（若有参考图，在对应描述中精准标注 `@图片1`）
        - `referenceNodeIds`: 引用的画布图片节点 ID
        - `size`: 默认横版宽幅 `16:9`（舒展衣料与花枝纵深）或肖像 `3:4`
   - 生成任务自动进入智影审批与渲染管线，通过 `task_get` 核验任务状态并将结果回写画布节点。

4. **动线美学排版 (`canvas_arrange_nodes`)**：
   - 节点创建与生成后，调用 `canvas_arrange_nodes(mode="flow")` 完成画布自左向右的工整排版。

### 模式二：生图/生视频工作台直达态 (Workbench Direct Mode)
- **开箱即用提示词卡片**：直接提取下方经过精细调优的 Midjourney V8.2 与 ImageGen / GPT-Image-2.5 提示词；
- **参数预设**：画幅比例默认 `16:9`（或肖像 `3:4`），采样步数与质量建议设定为高质量/4K档位；
- **推荐模型**：优先选用 `gpt-image-2.5` 或 `midjourney-v8.2`。

## 簪花女郎视觉 DNA 核心法则

撰写提示词时，必须严格遵守以下法则：

1. **横向舒展构图**：默认采用 `16:9` 横版构图，人物位于一侧黄金三分线，另一侧由飘逸披帛、伸展花枝、微虚背景展开横向空间纵深，拒绝狭隘的大头大特写。
2. **材质层次分明**：
   - 织锦/缎面必须表现出挺括厚重的哑光或微光泽；
   - 披帛与纱衣必须表现出轻薄半透明的透光折射；
   - 刺绣呈现立体针脚肌理，杜绝平面劣质印花感。
3. **定向温润主光**：上方偏侧 45 度的暖白色主方向光，辅以清冷微弱的反射环境光；高光唯独聚集在金线、水晶宝石与水润唇珠上。
4. **珠光晕克制原则**：柔焦珠光晕只允许出现在金银细工、珠宝和欧根纱反光边缘，皮肤必须保留真实质感与下颌阴影，严禁全图白光过曝。

## 双模型提示词工程规范

### 1. Midjourney V8.2
- **结构**：`镜头视点与横向空间 -> 东方女子神态姿态 -> 簪花冠与发式结构 -> 珠光织锦与透明披帛材质分层 -> 方向暖光与微量珠光晕 -> 辅色色彩分布 -> 排除项 -> --ar 16:9 --s 100 --c 0 --v 8.2`
- 纯正英文，词数 170-220 词，**必须严格以 `--v 8.2` 结尾**。
- 绝不使用 `8K`、`masterpiece`、`photorealistic` 等泛化废词。

### 2. ImageGen 中文提示词
- **结构**：`画幅比例 -> 东方女性沉静面容神采 -> 牡丹/玉兰花髻细节 -> 珠光云锦长袍与透光披帛 -> 单侧自然暖光照射与金线微泛珠光 -> 背景花枝虚化与典雅意境 -> 针对性负面约束`
- 纯正中文文学与摄影语言，严禁混入 Midjourney 参数。

## 画布交付前自检清单

1. **事实保真**：用户指定的花卉种类（牡丹、山茶、玉兰）、衣着主色、动作仪态是否完整体现；
2. **拒绝影楼俗艳**：是否排除了荧光绿、死亡芭比粉、大面积塑料珠串以及劣质假发包；
3. **五官真实写实**：眼部有无自然神采，是否避免了千篇一律的蛇精脸或严重磨皮；
4. **零本地命令行依赖**：严禁调用本地 Python 检查脚本，所有核验在 Agent 对话与画布操作流中闭环完成。
