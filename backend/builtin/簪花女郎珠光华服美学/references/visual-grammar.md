# 视觉语法

## 核心定义

“簪花女郎·珠光华服美学”不是一种暖色滤镜。以下六个条件应同时成立：

1. **克制的人物存在**：人物安静而非夸张，目光状态和嘴唇状态明确，面部由连续柔和明暗塑形。
2. **附着式发髻与冠饰**：黑发先形成清楚的结构体量；花、金丝、珍珠、水晶或珐琅饰件明确固定在发髻上，流苏从具体节点垂下。
3. **厚薄分层的华服**：珠光织锦或缎面承担厚重主衣，凸起金属花卉刺绣形成触感；透明欧根纱/披帛独立悬浮、折射并露出下层。
4. **可读的方向光**：暖白主光从画面上方一侧进入，冷色或中性补光保留颈部、下颌和衣褶内部建模。
5. **被限制的珠光晕**：只在金线、珍珠、水晶、织锦脊线和透明薄纱边缘开花；中间调与肤色不能一起漂白。
6. **构图中的静与动**：脸部稳定，衣袖、披帛、花枝、云层或前景散景形成一条可追踪的横向、斜向或 S 形运动路径。

缺少其中任意三项时，不应称为这套风格。

## 视觉 DNA

- **人物气质**：平静直视、侧望、远望或闭目；情绪温度克制、仪式化、略带疏离。
- **脸部构造**：理想化自然比例；眼睑线条清晰；虹膜在睁眼时可读；珊瑚色唇自然闭合或轻微张开；皮肤柔和修饰但保留体积。
- **发型行为**：黑发以光滑大体量为主、少量面侧细丝为辅；不能变成均匀湿发或无结构长发。
- **标志关系**：一项高识别成本的簪花/冠饰关系，加一项组织构图的袖、披帛、花枝、道具或云层关系。
- **材料隐喻**：花卉刺绣像从织物表面浮起的珠光浅浮雕；透明披帛像薄雾覆盖其上，但两者不可融成同一种塑料。
- **光学处理**：眼睛、近侧珠饰和焦点刺绣清晰；薄纱、花团和背景逐层柔化；散景有前后层级而非全屏奶油糊。
- **色彩逻辑**：桃暖肤色对比雾蓝/水青/石板灰空间；象牙白为织物基底；淡粉、珊瑚、玉绿、钴蓝和香槟金拥有各自局部区域。
- **情绪张力**：静止而克制的脸，被繁复、流动、反光的衣料与花饰围绕。

## 不锁定的变量

风格不锁定同一张脸、同一个花冠、同一套服装或同一姿势。允许变化：

- 正面、侧身、越肩、背身回望、俯首、仰望；
- 宫室、花园、云天、深色抽象背景、窗格或回廊；
- 牡丹、细碎白花、叶影、透明蝴蝶、玉笛、团扇或无道具；
- 象牙水青、灰蓝珊瑚、青铜金、深钴蓝与银白等分支；
- 胸像、腰像、三分之二像或环境肖像。

变化必须与布料、发丝、饰件和光线的物理反应一起变化，不能只换名词。

## 人物与服装编译

按以下顺序写人物：

`景别与位置 -> 身体方向 -> 头部回转 -> 目光/嘴唇 -> 发髻体量 -> 饰件固定与垂挂 -> 手和道具 -> 衣装边界`

按以下顺序写服装：

`不透明内层 -> 珠光主织物 -> 凸起刺绣 -> 半透明外层 -> 折叠/展开/飘动路径 -> 与身体和画框的关系`

不要用“盛唐复原”“明制复原”等历史定论。现有样本混合了宫廷、仙逸、时装化和数字肖像表达，本 Skill 是架空新中式人物美学，不承担服饰考据。

## 横版身份

16:9 不是改参数，而是重新安排横向空间。至少采用一项：

- 人物落在左/右三分区，另一侧形成明确负空间；
- 一只巨袖从边缘横贯画面下方；
- 花枝、披帛或乐器跨越开放中部；
- 云层、窗格、宫室或花团形成前中后景；
- 两个衣袖形成不对称 S 形包围。

除非用户要求特写，脸部不应吞掉整幅横版，冠饰、肩线、手、道具或主衣袖中至少两项应完整可读。
