# 跑偏修复矩阵

失败图是负面样本。先对照用户目标或原图，再修改最小责任项；不要把失败图重新当作风格参考。

| 症状 | 主要原因 | 最小修复 |
| --- | --- | --- |
| 变成纯白影棚、背景没有层次 | 背景与光线没有空间关系，或全局柔光过强 | 明确人物所在三分区和背景层次；加入 `subject remains brighter than a smoky khaki-gray / cool slate field`，并保留方向光与补光差 |
| 衣服全部泛白，蓝粉绿消失 | 珠光被误写成全局发光或过曝 | 指定每种颜色归属；写 `bloom confined to metallic thread, jewels and organza edges`；保留织物中间调 |
| 全图棕黄、橄榄或复古滤镜 | 暖光没有冷/中性补光，背景被暖色统治 | 加入冷蓝/中性填充；说明桃暖只属于皮肤，背景更冷或更暗；短负面加入 `sepia olive-cast` |
| 哑光插画、油画或平涂 | 缺少体积、反射与层级景深描述 | 加入连续面部渐变、连贯反射、焦点珠饰清晰、前后景逐层柔化；负面加入 `matte-illustration oil-painting` 中最接近的一项 |
| 皮肤像塑料或蜡 | 只写 smooth/flawless，且高光覆盖面太大 | 删除泛化皮肤词；写自然连续明暗、克制皮肤高光、下颌阴影和桃暖中间调 |
| 人脸变成极近特写，冠袖被裁 | 提示词先强调美貌/脸部，横版空间没有优先级 | 用景别、人物占比、三分区位置和完整冠饰/袖边开头；删除前置 beauty/portrait-quality 词 |
| 所有构图都变正面站姿 | 情绪版提供了相似人物审美但文本没有冻结方向 | 写清躯干朝向、头部回转、目光方向和主衣袖/道具路径；必要时用原图作为 Image Prompt |
| 花冠漂浮或流苏无重力 | 只有饰品清单，没有连接关系 | 写 `attached to the updo at ...`、`pearl chains descend from ...` 等固定点和垂挂方向 |
| 织锦、薄纱和金线融成乳白塑料 | 材料只按颜色描述，没有厚度与透明度 | 先写不透明厚织锦，再写凸起金属线，最后写可透见下层的透明欧根纱，明确 `separated from` |
| 刺绣变成平面印花 | 缺少表面拓扑 | 使用 `dense raised metallic peony embroidery`, `woven relief`, `thread ridges catching local light` |
| bloom 覆盖全脸和背景 | 局部光晕没有边界 | 指定最亮点与允许区域；写 `skin retains modeled midtones` 和 `localized bloom only` |
| 手或笛子被裁切、复制、融合 | 道具与手的关系不够早或不够具体 | 在首两句写一件道具、起止点、双手位置和完整可见；加入场景专属短负面 |
| 情绪版很好看但不听构图 | `--s` 太高或正文几何过弱 | 先加强几何与关系；仍失控时从已验证的 `--s 100` 降到 `--s 50` 做单变量对照 |
| 情绪版存在感不足 | 激活语句缺失，或用户实际没有启用目标情绪版 | 确认界面选择/`--p`；保留一条具体体积、反射、珠饰和景深激活句；如需试验仅将 `--s` 提到 150 |
| 无情绪版时人物普通、织物廉价 | 把组合成功误当成纯提示词成功 | 切换“无情绪版降级模式”，补全视觉 DNA，并明确这是近似重建；不要宣称等效 |

## 修复报告

用户给出失败图时，用四句话说明：

1. 目标中本应存在的事实；
2. 当前生成图的偏差；
3. 责任来自提示词、情绪版/参考角色、模型方差还是不确定；
4. 最小修改和这次只改变的参数。

一次最多修三项。构图通过后，不因颜色问题重写姿势；材质通过后，不因面部问题更换整套服装。
