# QA 与可选扩展

## 核心 QA

- 六项交付均有真实终态，失败项不能用计划文本占位。
- 所有下游节点连接同一个已确认 Logo 素材节点。
- Logo 图形、品牌名、Slogan、主辅色和字体气质跨资产一致。
- 手机样机只出现两台，设备边框完整，屏幕约 9:19.5，不纵向拉伸。
- 包装物料遵守真实品牌/产品事实，不编造认证、成分、价格或促销。
- IP 四视图结构连续，不变成四个不同角色。
- 动效不改变 Logo，且真实可播放。
- 文字有拼写问题时只返工相应节点；AI 概念图不冒充印刷生产文件。
- Logo 尚未完成矢量重建、字体授权或商标检索时必须明确说明。

## 扩展 A：单体 IP 3D

1. 先使用 IP 四视图作为参考，生成一张只有单个正面角色、纯背景、无标注的 1:1 图片。
2. 把该单图节点连接到 `threed` 节点。
3. 查询平台启用的 3D 模型和精确合同后运行。

禁止直接把四视图整板连接到 3D 节点。

## 扩展 B：门店/空间场景

参考已确认 Logo，生成适配行业的门店或空间。锁定：完整门头、品牌色在建筑和家具中的克制应用、真实材料、合理照明、可进入的空间结构。不要把一张平面海报贴满整个建筑替代空间设计。

## 扩展 C：宣传海报

竖版优先。层级为 Logo/品牌名 → 主视觉 → Slogan → 必要信息与 CTA。日期、地点、价格和活动规则必须来自用户，不得编造。

## 扩展 D：生活方式营销图

把品牌产品自然放入真实生活情境，采用编辑感摄影而非硬广摆拍。Logo 可见但不过度居中，环境只用少量品牌色呼应。真实人物或受保护身份必须有授权素材。

## 返工规则

- 修改品牌系统锁：重新检查所有下游资产。
- 修改单张版式或文字：只重做对应节点。
- 生成失败：保留已通过项，只重试失败 slot，不重新提交整批。
