# 营销宣传册领域参考

## 何时读取

在制定方案、处理边界案例或执行最终领域检查时读取本文件。通用事实、权利、任务状态和生产要求由共享专业生产契约负责，本文件只保留营销宣传册特有知识。

## 决策要点

- 先做内容架构，再做视觉。
- 三折页必须同时检查平铺顺序与折后顺序。
- 失败模式：联系方式被模型改写、长文案过小、只交样机、跨页元素落在装订或折线。

## 工作流索引

1. 核对内容源与缺失项
2. 建立读者旅程和信息层级
3. 规划页序、折法与内容分配
4. 锁定版式系统和生产规格
5. 确认平面页序与关键文案
6. 逐页生成视觉稿
7. 执行校对与印前检查

## 交付最低要求

- 内容缺口和 copy lock
- 页序/面板架构
- 逐页视觉稿与排版说明
- 印前和校对清单

## 失败判定

- 未满足：阅读顺序正确
- 未满足：关键文案未被改写
- 未满足：平面稿和样机明确区分
- 未满足：出血、边距、折线和字号可生产
