# 表演、商品资产与连续性

只在创建演员、商品、场景、道具、关键帧或排查跨镜漂移时读取本文件。

## 1. 稳定资产 ID

- 商品：`PRODUCT-001`
- 包装/使用状态：`STATE-PRODUCT001-01`
- 演员身份：`CHAR-001`
- 造型：`LOOK-CHAR001-01`
- 场景：`LOC-001`
- 道具：`PROP-001`
- 特殊/3D 资产：`ASSET-001`

版本以 `-v001` 递增；Manifest 的 `approvedVersion` 指向可用版本。禁止覆盖旧版或用模糊文件名引用。

## 2. 商品身份圣经

至少记录：

- 正面、背面、左右侧和必要俯视/底部参考。
- 宽高厚比例、轮廓、材质、颜色、反射和透明度。
- Logo、标签、按钮、接口、屏幕、封口和图案的位置关系。
- 开封、关闭、使用中、剩余量和搭配配件状态。
- 正确握持、穿戴、安装、倾倒、喷涂或操作方式。
- 禁止改变的包装、结构、文字和品牌特征。

精确商品文字和价格由后期叠加。生成画面中的商品文字只用于形体参考，不能作为最终合规文字。

## 3. 演员身份与剧情状态

身份锚点：年龄感、面部几何、肤色、体型、发型、不可变标记。状态锚点：服装、配饰、妆容、伤痕、湿度、污渍、情绪和持有物。

为演员批准：正面、左右 3/4、侧面、全身比例和表情范围。不同镜头重复传入身份与当前造型参考。

UGC 真实感来自：

- 自然混合光、生活空间和合理手机镜头距离。
- 可见皮肤纹理、衣物褶皱、轻微不对称和呼吸。
- 目光、停顿、吞咽、重心和微表情，而非持续大幅手势。
- 商品操作清楚；复杂手部动作拆镜，必要时使用商品特写或道具替手镜头。

不要用过度磨皮、影棚级完美、随机镜头抖动或低清晰度伪装 UGC。

## 4. 表演节拍

每镜标记：

```text
进入状态 → 触发 → 内在判断 → 可见选择 → 商品动作 → 反应 → 结束状态
```

对白镜头说明说话对象、视线、速度、重音和反应镜头。嘴型困难时缩短台词、拆分镜头或把信息转为旁白/字幕，不让人物高速念完长文案。

## 5. 场景和道具

场景记录拓扑、出入口、固定家具、桌面/货架、主光源、时间状态和可复用机位。商品放置、拿起和归还的位置必须连续。

道具记录持有者、左右手、开关/破损/消耗状态和生效镜头。商品本身同时遵守商品身份与道具连续性。

## 6. 生成顺序

1. 入库用户真实商品、品牌和演员参考。
2. 批准商品身份板和使用状态。
3. 批准演员身份板与造型。
4. 批准场景拓扑和关键道具。
5. 生成商品 + 演员 + 场景组合测试。
6. 组合通过后生成独立分镜关键帧。
7. 关键帧通过后逐镜生成视频。

所有 AI 资产只通过智影原生工作台。每个请求显式传入所需参考素材，不写“与上一张一致”来代替引用。
