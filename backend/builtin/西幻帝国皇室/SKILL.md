# 西幻帝国皇室 · 视听导演与画布协同系统

将用户的简短场景或参考图，编译为严谨宏大、充满史诗压迫感与权力张力的“西幻帝国皇室”视听大片。
依托哥特式宫廷建筑、冷铂金与暖古金材质分工、深黑天鹅绒负空间以及高对比度单一主光系统，在智影画布上实现从创意感知、节点落位到原生图像生成的全流程闭环。

---

## 工业化执行标准 (双模执行管线)

### 模式一：画布 Agent 执行管线 (Canvas Agent Automation)
1. **画布感知与多模态审图 (`canvas_get_state` + `canvas_inspect_image`)**：
   - 启动时调用 `canvas_get_state` 读取当前画布节点、已有资产与 `snapshotHash`。
   - 若画布上已有用户上传的王座、贵族人物、铠甲、礼服或大教堂场景图片节点，**必须调用 `canvas_inspect_image(nodeId)` 观察真实画面**：
     1. **权力主体与仪态**：王冠形态（锐利冷铂金尖刺/繁复复古雕花）、冷峻深邃的目光、尊贵克制的仪态与手势（绝非现代浮夸夸张动作）；
     2. **面料与金属材质**：暗色厚重天鹅绒披风、古老金线刺绣、高反光镜面胸甲、黑曜石地面倒影；
     3. **宏大空间与光影基调**：高耸哥特式尖肋拱顶、巨型彩色花窗透过的斜射光束（丁达尔效应束光）、深邃暗部负空间。
   - 提取到的真实视觉事实准确注入提示词中，杜绝凭空臆造。

2. **画布实体落位与拓扑连线 (`canvas_apply_ops`)**：
   - **视听方案节点**：调用 `canvas_apply_ops` 创建 `markdown` 节点（`nodeType: "markdown"`, `title: "西幻帝国皇室·视觉方案"`）：
     - 记录所选风格分支（参见 [`references/visual-grammar.md`](references/visual-grammar.md)）；
     - 记录核心权力事件（登基加冕、御前议政、骑士授勋、假面暗流、神兽契约）；
     - 输出 ImageGen 中文原生提示词与 Midjourney V8.2 提示词及负面漂移约束。
   - **生图资产卡**：调用 `canvas_apply_ops` 创建 `image` 草稿节点（`nodeType: "image"`, `title: "帝国皇室-视觉画面"`）。
   - **建立连线**：若有参考图片节点，在 `canvas_apply_ops` 中使用 `connect_nodes` 建立从源参考图至目标 `image` 节点的连线依赖。

3. **模型协商与原生媒体生成 (`model_list` + `generate_media`)**：
   - 当用户确认需要出图时：
     1. 调用 `model_list(mode="image", referenceNodeIds=[...])` 查询当前生效的高画质生图模型（如 `gpt-image-2.5` 4K 或相关特惠渠道）；
     2. 调用 `generate_media` 发起生成审批与任务提交：
        - `mode`: `"image"`
        - `nodeId`: 目标 `image` 节点 ID
        - `title`: 节点名称（如 `加冕大典-王座之巅`）
        - `prompt`: 完整提示词（若有参考图，在对应描述中精准标注 `@图片1`）
        - `referenceNodeIds`: 引用的画布图片节点 ID
        - `size`: 场景默认宽幅 `16:9`；人物立像肖像默认 `3:4`
   - 生成任务自动进入智影审批与渲染管线，通过 `task_get` 核验任务状态并将结果回写画布节点。

4. **动线美学排版 (`canvas_arrange_nodes`)**：
   - 节点创建与生成后，调用 `canvas_arrange_nodes(mode="flow")` 完成画布自左向右的工整排版。

### 模式二：生图/生视频工作台直达态 (Workbench Direct Mode)
- **开箱即用提示词卡片**：直接提取下方经过精细调优的 Midjourney V8.2 与 ImageGen / GPT-Image-2.5 提示词；
- **参数预设**：场景默认宽幅 `16:9`；人物立像肖像默认 `3:4`，采样步数与质量建议设定为高质量/4K档位；
- **推荐模型**：优先选用 `gpt-image-2.5` 或 `midjourney-v8.2`。

## 帝国皇室视觉 DNA 与核心法则

撰写提示词时，必须严格遵守以下法则（参考 [`references/material-light-system.md`](references/material-light-system.md) 与 [`references/scene-library.md`](references/scene-library.md)）：

1. **权力秩序与空间比例**：构图呈现严谨的纵深与权威对称。前景为冷硬石柱框景，中景为权力核心主体（王座/统帅），远景为浩大幽暗的帝国建筑空间。
2. **材质严格分工**：
   - **冷铂金**：负责建筑主干骨架、铠甲锐边、权力冷酷意志；
   - **暖古金**：负责皇家徽章、仪式法器、烛火光晕与领口刺绣微光；
   - **黑曜石与深黑天鹅绒**：提供大面积纯净沉稳的负空间，衬托主体。
3. **单一戏剧性主光源**：全场景只允许一个具有逻辑来源的主光源（高窗斜射夕阳、巨型吊灯单一束光或权杖圣光），辅以克制的冷铂金侧逆轮廓光，严禁全屏均质亮光或塑料感泛黄滤镜。
4. **服饰与神态的尊贵感**：神态威严内敛，强调目光与手势带来的空间压迫感，拒绝低俗暴露设计或轻浮笑容。

## 双模型提示词工程规范

### 1. Midjourney V8.2
- **结构**：`景别构图与大空间 -> 权力主体与动作姿态 -> 皇家服饰铠甲与材质 -> 光源方向与丁达尔束光 -> 画面色彩与负空间 -> 排除项 -> --ar 16:9 --v 8.2`
- 纯正英文，**必须严格以 `--v 8.2` 结尾**。
- 绝不使用 `masterpiece`、`8K`、`photorealistic` 等泛化废词。

### 2. ImageGen 中文提示词
- **结构**：`画幅与画质定位 -> 哥特式帝国场景空间 -> 核心人物与权力仪式事件 -> 铂金古金铠甲面料细节 -> 单一高反差主光与阴影层次 -> 画面庄重氛围 -> 负面漂移排除`
- 纯正中文文学与视听语言，严禁混入 Midjourney 语法参数。

## 画布交付前自检清单

1. **事实保真**：用户指定的皇室身份、圣物道具、事件行动是否完整保留；
2. **文化纯度防漂移**：严格排查是否混入了中式宫殿、汉服仙侠飘带或现代都市元素；
3. **空间与光线合一**：光线来源是否清晰可辨，暗部是否保留有深度的层次感；
4. **零本地命令行依赖**：严禁调用本地 Python 校验脚本，所有检验在 Agent 对话与画布操作流中闭环完成。
