# 双模型提示词编译规则

ImageGen 与 Midjourney 共享同一内容骨架，但必须分别用适合模型的语言编写。

## 共享骨架

1. 画幅、景别、视角与主体位置。
2. 主体身份、数量、姿态、方向、目光和核心动作。
3. 权力事件与最重要的空间/道具关系。
4. 哥特帝国空间、前中后景和尺度参照。
5. 服装或甲胄轮廓、主材质及双金属分工。
6. 头发、披风、旗帜、雨雪、液体、烟尘或群像的运动物理。
7. 主光位置、冷铂金辅光、暗部色彩和景深。
8. 一句情绪总结。
9. 只针对当前场景的负面约束与参数。

## ImageGen 中文提示词

- 使用清晰、连续的中文自然语言，不使用标签堆砌。
- 开头先写画幅和画面骨架，再写人物与事件，不以“高清、杰作、超精细”开头。
- 明确前景、中景、远景；人物与道具关系用动词描述。
- 材质必须说明位置、硬度、透明度、反射或流动行为。
- 明确一个主光源的位置和方向，冷光只作轮廓或环境补光。
- 结尾写“必须保留”和简洁负面约束，不包含 `--ar`、`--v` 或任何 Midjourney 参数。
- 建议长度约 260–480 个中文字符；复杂群像可适当增加，但不要重复同义词。

建议顺序：

`横竖比例与镜头 -> 主体与动作 -> 权力关系 -> 空间层次 -> 服装/材质 -> 运动 -> 光色/景深 -> 必须保留 -> 负面约束`

## Midjourney 8.2 英文提示词

- 使用一段连贯、优先级清楚的视觉英文。
- 开头先锁定 shot、viewpoint、subject count、dominant action 和主要关系，再写人物美学。
- 不使用空泛质量词、艺术家名、电影名或未经用户提供的相机品牌。
- 正文建议约 120–190 个英文单词；复杂群像或神兽场景可到 220 词。
- 负面参数只排除最近的漂移，不堆砌所有可能问题。
- 参数位于正文之后，并严格以 `--v 8.2` 结束。

建议顺序：

`shot and dominant relationship -> subject presence and action -> Gothic imperial setting -> costume/material hierarchy -> motion physics -> key light, platinum rim and dark palette -> emotional finish -> --no -> parameters -> --v 8.2`

## 默认参数

- 环境、仪式和宫廷叙事：`--ar 16:9 --raw --s 320 --c 7 --v 8.2`
- 骑乘、出征、宣战和强动作：`--ar 16:9 --raw --s 330 --c 9 --v 8.2`
- 单人肖像或全身立像：`--ar 3:4 --raw --s 280 --c 5 --v 8.2`
- 用户指定比例、风格化程度或随机度时服从用户；不得静默覆盖。
- 不添加 `--hd`、`--seed`、`--sref`、`--oref`、`--profile` 或 URL，除非用户明确提供且要求保留。
