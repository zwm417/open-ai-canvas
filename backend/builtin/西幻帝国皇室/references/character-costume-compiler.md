# 人物与皇室服装编译器

## 主体自由

- 不内置固定姓名、固定女皇、固定发色、固定年龄或固定脸型。
- 严格保留用户明确指定的性别、年龄段、身份、族群、人数、身体状态和动作。
- 用户没有指定性别、年龄或外貌时，只写与身份和情绪有关的可见特征，不随意补充人口属性。
- 用户没有指定人物时，不添加国王、女皇、侍从或士兵。

## 人物存在感顺序

`身份与画幅 -> 姿态与方向 -> 目光与表情 -> 手势与权力关系 -> 发型和头发运动 -> 服装轮廓 -> 材质与徽章`

- 权威来自站位、视线、手势、他人的反应和空间尺度，不依赖裸露、夸张身材或泛化“绝世美人”。
- 表情使用可见温度：克制、审视、冷静、哀悼、决绝、疲惫、警觉或胜利后的疏离。
- 不把 `beautiful`、`stunning`、`voluptuous`、`sexy` 当成身份描述的默认组成。

## 身份与服装

### 君主与王储

- 结构：长袍、披风、礼服、金属束腰、肩部骨架、纹章胸针或王室腰带。
- 冠饰：西欧尖拱、百合、荆棘、城堡塔尖、宝石镶嵌或简洁王冠；不使用凤冠或中式步摇。
- 场景决定服装：议政偏克制深色，仪式偏象牙与铂金，战争偏甲胄与披风。

### 战争统治者与皇家骑士

- 结构：可活动板甲、锁子甲、皮革连接、护肩、护臂、战裙或披风。
- 必须说明受力、关节与穿戴层次，避免整套甲胄熔成无结构金属。
- 王室身份通过冠形头盔、纹章、披风、宝石扣或军队反应体现。

### 宫廷法师、占星师与祭司

- 结构：长袍、披肩、金属骨架、仪式腰带、手套、星盘、权杖或圣物。
- 魔法必须与一个器物、手势或空间装置相连，不使用随机光球堆叠。

### 宫廷群像

- 只突出一个权力焦点。廷臣、将领、乐师、侍从和卫兵应有身份层级与站位秩序。
- 避免复制脸、复制姿势、重复冠饰和无意义人群填充。

## 服装编译顺序

1. 先确定身份与事件需要的活动能力。
2. 再确定整体轮廓：垂直、披风三角、甲胄倒三角、钟形裙摆或修长柱形。
3. 选择一种主面料或甲胄基底。
4. 将铂金用于结构边缘，将古金用于徽章、刺绣或仪式焦点。
5. 根据动作安排开口、褶皱、披风和裙摆，不为展示身体而破坏功能。
6. 最后加入一件高识别度物件：王冠、面具、权杖、纹章披风、宝石长靴或冠形头盔。
