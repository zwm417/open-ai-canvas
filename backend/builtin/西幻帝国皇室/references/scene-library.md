# 皇室场景与动作关系库

只在当前请求涉及对应活动时使用。先保护人物、动作与道具关系，再添加建筑和装饰。

## 登基、加冕与朝见

- 关系骨架：`君主位于王座或阶梯轴线 -> 冠冕或权杖与身体明确接触 -> 臣民/卫兵以站位和视线指向君主`。
- 构图：低机位、中轴或轻微偏心，保留王座、尖拱或巨柱作为尺度参照。
- 避免：皇冠悬浮、权杖穿手、臣民背向君主、人物被王座吞没。

## 议政、战略会议与审判

- 关系骨架：`统治者控制地图/文件/证物 -> 将领或廷臣围绕但不抢焦点 -> 建筑与旗帜建立帝国秩序`。
- 手势：一只手压住桌面、指向地图、举起法令或审视被告；不要让两只手同时做不相干动作。
- 避免：地图像界面、微缩建筑粘连、人物复制、无意义发光文字。

## 阅兵、宣战与城门仪式

- 关系骨架：`统治者面向军队或城门 -> 军队形成纵深和秩序 -> 旗帜、雨雪、披风共享风向`。
- 构图：低机位或广角环境镜头，保留堡垒、军阵和天空层次。
- 避免：士兵比例混乱、武器穿插、旗帜无风向、现代军事装备。

## 骑乘、出征与凯旋

- 关系骨架：`骑手与坐骑正确接触 -> 缰绳连接手与马具 -> 速度方向驱动披风、鬃毛和背景模糊`。
- 镜头：低侧向追拍、三分之四前视或远景队列，三者只选一个。
- 避免：骑手悬浮、额外腿、坐骑断裂、缰绳穿过身体、建筑过度模糊。

## 假面舞会、歌剧与宫宴

- 关系骨架：`主角完成一个清晰动作 -> 群像通过停顿、转身或注视形成权力关系 -> 舞台/舞池/镜廊建立空间`。
- 动作：转身、摘下面具、举杯、谢幕、独舞或穿过静止人群；一次只选一个。
- 避免：多人脸复制、面具粘脸、手指错误、裙摆糊成背景、烛光过曝。

## 仪式魔法与王朝奇迹

- 关系骨架：`手势或权杖启动明确器物/纹章/地面阵列 -> 魔法沿连续路径传播 -> 周围人物和材质接受同一光源反射`。
- 魔法机制：液态金、铂金薄纱、金箔纹章、镜水涟漪或熔金裂隙只选一种。
- 避免：随机光球、无来源能量、魔法遮脸、手部与液体粘连、全屏粒子。

## 神兽契约

- 关系骨架：`皇室主体与神兽通过触摸、目光、缰具或共享方向建立关系 -> 神兽拥有完整典型轮廓 -> 帝国空间提供尺度`。
- 人兽比例必须符合叙事；巨型神兽可占据画面大部，但不得裁掉关键头部和关节。
- 避免：羽毛与甲片混成塑料、喙甲熔脸、额外翅膀、人兽肢体融合。

## 无人皇室场景

- 使用空王座、封闭城门、遗落王冠、熄灭的舞厅、战后议政桌或神兽巢穴表达权力缺席。
- 至少保留一个明确叙事线索和一种帝国空间秩序；不要自动补人物。
