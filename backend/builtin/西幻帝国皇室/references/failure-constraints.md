# 失败模式与负面约束

只选择与当前请求相关的约束。负面词不是越多越好。

## 人体、动物与接触关系

- 人物近景或手势：畸形手指、多余手指、手掌融合、左右手错位、首饰粘连。
- 骑乘：额外腿、骑手悬浮、马腿断裂、缰绳穿模、坐骑与裙摆融合。
- 神兽：额外翅膀、羽毛粘连、喙甲熔脸、关节缺失、人兽肢体融合。
- 群像：重复面孔、复制姿势、比例漂移、无层级人群。

## 建筑与空间

- 哥特尖拱、肋拱、楼梯、桥梁、阳台和王座必须服从同一透视。
- 排除重复塔楼、断裂承重、融化墙体、悬空栏杆、楼梯与裙摆粘连。
- 排除现代城市天际线、摩天楼、汽车、电线、霓虹招牌和科幻界面。

## 材质

- 排除皮肤金属化、塑料皮肤、蜡像脸、全屏黄色滤镜、无来源神光。
- 排除液态金像黏胶包裹身体、镜水像石油洪水、铂金和古金混成单一亮黄色材料。
- 排除铠甲无关节、珠宝融化、羽毛金属化、石材像软布。

## 风格漂移

- 默认排除汉服、和服、中式凤冠、步摇、仙侠宫殿、东方龙、动漫脸和廉价游戏 UI。
- 不默认排除用户明确要求的跨文化元素；若用户要求混合，保留其指定内容并只排除非目标漂移。
- 排除现代高定摄影棚、红毯背景和普通婚纱照，除非用户明确要求时尚化。

## 光线与画面

- 排除同时出现多个互相冲突的太阳、窗光、烛火和熔岩主光。
- 排除高光大面积爆白、暗部死黑、主体与背景同亮度、随机彩色粒子和全屏散景。
- 排除文字、字幕、徽标、水印、边框和界面元素。

## 生成负面约束的方法

1. 选择 1–2 个与主体有关的形态风险。
2. 选择 1–2 个与当前动作或接触关系有关的风险。
3. 选择 1–2 个与空间或材质有关的风险。
4. 默认加入文字、标志和水印；若画面需要真实纹章，不排除纹章本身，只排除乱码文字。
5. 中文负面约束通常控制在 6–12 项；Midjourney `--no` 控制在 4–10 个短语。
