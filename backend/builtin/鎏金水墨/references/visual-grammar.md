# 鎏金水墨幻想视觉语法

## 核心定义

本风格由四个同时成立的条件构成：

1. 主体形态保真：主体仍能凭轮廓、关键部件与动作被准确识别。
2. 分层鎏金材料：至少一种明确的金色材料机制，与湿墨、黑漆、树脂、玉质、矿彩或天气质感形成对比。
3. 冷暗空间与局部暖光：蓝黑、青灰或近黑负空间承托少量香槟金高光，不做均匀金黄。
4. 诗性空间组织：一个主形状、一条辅助弧线或 S 曲线、清楚景深与可呼吸的留白。

缺少主体形态保真时只是风格覆盖；缺少材料分层时只是普通金色滤镜；缺少冷暗负空间时容易变成廉价奢华海报。

人物或类人主体还必须通过 `hair-costume-grammar.md` 选择发饰密度与服装层次。该模块只决定造型工艺，不决定性别、身份、眼睛状态或动作，也不得用于非人物主体。

## 五个风格分支

### 1. 梦幻透明鎏金（默认）

- 适用：人物、动物、神兽、花卉、器物、抽象生物、近景或单体立像。
- 主材料：透明琥珀金液/玻璃，辅助少量花丝金属或碎金箔。
- 形态：薄片、细丝、滴状、液膜和一到两条弧流；必须透明折射，背景仍可见。
- 光色：深青黑场域、暖象牙主体、香槟金高光、极弱冷青边光。
- 情绪：梦幻、神秘、精致、静谧或有克制力量。

### 2. 水墨金箔世界

- 适用：山水、建筑、巨树、服装延展、世界场景、微缩景观和抽象地形。
- 主材料：湿墨或黑漆与贴附碎金箔；可辅以白色树脂云、宣纸和矿物青绿。
- 形态：金箔只沿山脊、裂纹、树根、鳞片、衣褶、波纹或建筑节点附着。
- 光色：冷青黑大场域，暖色掠光沿结构短暂显现。
- 情绪：辽阔、古老、内省、东方山水式留白。

### 3. 雨雪湿光

- 适用：雨、雪、雾、湿发、湿毛、湿石、雨夜街巷或风雪荒野中的任何主体。
- 主材料：湿润真实表面、稀疏金痕、透明水膜和天气粒子。
- 形态：鎏金只占小面积，可沿颧骨、羽毛边、毛发纹、甲片、树皮或雨幕出现。
- 光色：冷青灰天气，暖肤色或主体局部被低角度金光托起。
- 情绪：触觉化、亲密、脆弱、坚韧；装饰密度低。

### 4. 花丝圣像

- 适用：仪式人物、神兽正面像、祭器、面具、王座、门扉、雕像或对称构图。
- 主材料：实心花丝金属与透明金液分层共存；可有珍珠、月弧或圆盘，但都为可选。
- 形态：一个巨大圆、月弧或椭圆作为主框架，主体居中或位于三分线。
- 光色：近黑背景、暖金主光、局部强反射和受控 bloom。
- 情绪：庄严、华丽、神圣；不等同于固定神女，不自动添加人脸或闭眼。

### 5. 矿彩树脂梦境

- 适用：花卉、海洋生物、地貌、器物、抽象形态、桌面微缩世界。
- 主材料：象牙树脂、半透明玉质、青绿矿彩、朱砂小点、湿墨和少量金箔。
- 形态：颜色分区清楚，像凝固颜料海、透明波浪或切开的矿层。
- 光色：柔和顶光或侧光，局部金色在树脂内部折射。
- 情绪：超现实、精工、宁静、收藏品般珍贵。

## 金色材料分层

### 实心花丝金属

- 视觉：不透明、硬边、清晰镂空、拉丝或锤纹表面。
- 位置：确实需要结构强度的冠、角饰、甲片、器物、门扉、桥梁节点或雕塑框架。
- 禁止：软化、熔解、长成无意义金色触手。

### 透明琥珀金液/玻璃

- 视觉：透明折射、带厚度、亮边、内部仍能看见背景或主体。
- 位置：环绕主体的薄膜、弧流、液滴、细丝、尾迹或透明浪。
- 禁止：不透明金管、岩浆、火焰、石油、全脸覆盖。

### 贴附碎金箔

- 视觉：薄、破碎、有缺口、紧贴粗糙表面，只在受光角度闪现。
- 位置：皮肤彩绘、毛发边缘、鳞片纹、树皮、裂纹、山脊、衣褶、墨迹或器物纹理。
- 禁止：均匀镀金、自发光、无结构地漂满全画面。

## 材料预算

- 稀疏鎏金：约 5%–15% 的可见表面，适合雨雪近景和真实质感。
- 平衡鎏金：约 15%–30%，适合默认单体或叙事场景。
- 华丽鎏金：约 30%–45%，只适合花丝圣像；仍需保留冷暗负空间和主体清晰区。
- 上述比例是构图思考标尺，不要求在提示词中机械写出；用户明确“极简”或“极繁”时可调整。

## 构图语法

- 亲密近景：脸、眼、兽首、花蕊、器物细节；前景液滴或发丝虚化，主体关键部件保持清晰。
- 单体立像：主体占主画面，弧形金液或圆盘作为辅助框架，不能吞没轮廓。
- 环境叙事：前景可触材质、中景主体与动作、远景墨云或冷暗空间。
- 微小尺度锚点：用于建筑、巨树、山水或巨大抽象形态；人物可有也可无。
- 顶视微缩：纸、树脂、矿彩、墨迹和器物形成超现实桌面世界。
- 正面对称：适合器物、门扉、雕像和仪式主体；不要自动变成人物圣像。

每张图选择一个主构图，不同时叠加顶视、低机位、正面特写和超广角。

## 光色控制

- 主光只选一个：暖色侧光、低角度逆光、顶部聚光或移动感掠光。
- 冷青补光必须弱于主光，只用于暗部边缘和材质分离。
- bloom 与 halation 只围绕少数金属/透明液体高光，不覆盖主体五官或关键结构。
- 暗部应有蓝黑、青灰、深墨绿层次，不做纯死黑。
- 暖色以香槟金、旧金、琥珀金和暖象牙为主，避免纯黄、橙红满屏。
- 朱砂只用于小面积视觉节点；用户未要求时不自动添加。

## 相邻风格排除

- 通用游戏 CG、塑料皮肤、廉价金色角色皮肤。
- 西式天使、教堂圣光、巴洛克金色堆饰，除非用户明确混合。
- 岩浆、火焰、闪电、激光、霓虹和灾难爆炸。
- 全身金属化、整景熔化、全屏金粉和没有物理来源的普遍发光。
- 平面敦煌壁画或普通古风插画；本风格强调真实材料、空间景深和局部折射。
