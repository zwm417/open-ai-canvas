# 任意主体编译规则

## 先锁主体，再加风格

每次先建立两张内部清单：

### 形态锁

- 主体名称与类别。
- 数量。
- 典型轮廓。
- 必须存在的部件及其数量、位置和比例。
- 动作、姿态、视线、表情或物理状态。
- 与环境、道具和其他主体的关系。
- 人物分支另锁：身份与时代、发型结构、发饰固定关系、服装轮廓与内外层、织物透明度，以及这些结构是否适合当前动作。

### 风格承载区

- 表面区：皮肤彩绘、毛发边缘、羽毛、鳞片、树皮、岩壁、衣褶、器物刻纹。
- 内部区：透明躯体、树脂、玉石、玻璃或抽象能量内部可见的金色脉络。
- 环绕区：薄膜、弧流、液滴、丝带、雾、雨幕或圆盘。
- 环境区：山脊、裂纹、树根、云边、水纹、纸面墨迹和建筑节点。

优先在不破坏轮廓的区域施加风格。主体识别所依赖的脸、眼、喙、角、爪、轮子、门洞、把手等关键部件不得被金液遮没。

## 主体类别

| 主体类别 | 形态锁重点 | 推荐风格承载方式 | 常见错误 |
|---|---|---|---|
| 人物或群像 | 身份、人数、姿态、眼睛状态、发型与饰件连接、服装层次、时代和动作 | 发饰局部花丝、空间透明弧流、衣褶金箔、湿发/雨雪 | 自动改成女性神女、闭眼、巨型金冠、泛化古装或静态肖像 |
| 普通动物 | 物种轮廓、四肢、耳尾、毛羽鳞和运动姿态 | 毛发/羽毛/鳞片边缘碎金，透明液体尾迹 | 人脸化、多肢、全身金雕、失去物种特征 |
| 神兽或幻想生物 | 用户给出的神话形态、头/翼/腿/尾数量 | 内部金色脉络、局部花丝甲片、环绕弧流 | 用装饰覆盖 canonical morphology，随意加头或翅 |
| 植物 | 主干、分枝、叶形、花形、根系和生长方向 | 树根/叶脉金箔、树脂花瓣、雨露折射 | 变成金属雕塑、分枝复制或花瓣熔化 |
| 建筑或空间 | 承重、连接、入口、层级、透视和功能 | 结构节点花丝金属、裂纹金箔、湿漆地面 | 墙体融化、无承托悬浮、金液堵住入口 |
| 山水或地貌 | 地平线、山脊、水系、尺度与前后景 | 山脊碎金、墨云、树脂水面、矿彩分区 | 云爆炸、整座山变金块、空间被雾抹平 |
| 器物或产品 | 外轮廓、开合关系、功能部件、表面工艺 | 刻纹碎金、花丝框架、透明液膜 | 改变功能、遮住开口、生成品牌字或无意义零件 |
| 抽象形态 | 主拓扑、流向、节奏、密度和空白 | 透明金液、墨迹、树脂、金箔岛 | 所有材料混成黄褐色漩涡，没有主形状 |
| 无人空景 | 地点、时代、天气、主结构和情绪 | 环境裂纹金箔、掠光、湿墨/树脂层 | 擅自加入神女、行者、动物或雕像 |

## 动作与状态保真

- 睁眼、闭眼、回望、奔跑、跃起、潜游、飞行、缠绕、开花、崩裂等状态都由用户决定。
- 动态主体可采用明确的瞬间定格和方向性构图，不因风格偏静谧就擅自改成站立或沉睡。
- 群体先写数量、分组和互相关系，再写鎏金装饰。
- 若用户只给出名词，选择最能表现其典型轮廓的自然状态，不自动采用神女姿态。

## 人物造型最小字段

当主体是人物或类人形态时，在进入风格编译前至少确定：

1. 发型结构：披发、半束、低髻、高髻、辫束、短发或用户指定结构；不可只写“长发飘逸”。
2. 发丝状态：干燥或湿润、整齐或松散、主运动方向，以及贴面碎发的数量要克制。
3. 饰件连接：簪穿过哪个发髻、梳固定在哪侧鬓后、冠沿哪条发际或髻座承托、流苏由哪个饰件垂下；不可只列名词。
4. 服装轮廓：贴身、宽袖、窄袖、披风、长裙、甲胄、现代礼服等，服从身份、时代和动作。
5. 服装分层：至少说明不透明内层和主体外层；使用透明纱时必须保留有覆盖力的内层。
6. 织物行为：丝绸的柔亮褶皱、锦缎的厚重纹理、纱的透光边缘、水袖的受力方向；不得把所有材质写成同一种亮塑料。
7. 鎏金落点：从衣领、袖口、腰封、裙摆、褶皱或缝线中选择 1–3 处，不做全身均匀镀金。

用户给出的性别、年龄、眼睛状态、发型、服装类别和时代均为不可改动事实。风格样本中的金冠、花钿、闭眼和神女身份都不是默认字段。

## 五个编译示例

### 黑豹穿过雨夜竹林

- 形态锁：一只睁眼黑豹、低身奔跑、四肢和长尾完整、竹林和斜雨。
- 风格承载：湿毛边缘少量碎金，雨幕中一条透明琥珀金弧流，蓝黑负空间。
- 不添加：人脸、金冠、闭眼、静止坐姿、全身金属化。

### 巨型水母漂浮在海上

- 形态锁：钟形伞体、透明触手、海面与漂浮状态。
- 风格承载：伞体内部金色脉络、部分触手为透明金液、远处墨云。
- 不添加：鸟翼、龙头、人物身体或不透明金色触手团。

### 古老山门立于风雪峡谷

- 形态锁：门洞可通行、结构有承托、峡谷与风雪方向清楚。
- 风格承载：石纹裂隙碎金、湿黑漆门扇、少量琥珀冰膜。
- 不添加：神女、宫殿群、火焰、霓虹或堵住入口的金液。

### 一枚悬浮的青铜面具

- 形态锁：面具外轮廓、眼孔、鼻梁、边缘厚度和正面视角。
- 风格承载：旧金花丝边框、局部透明金膜、蓝黑背景。
- 不添加：真实人脸、完整头部、文字、品牌或无功能机械件。

### 无人物的墨色云海

- 形态锁：云海、远山、水平纵深与大留白。
- 风格承载：远山脊线贴附碎金，暖掠光依次显现，近景湿墨云。
- 不添加：人物、舟、鸟、宫殿、神兽或金色爆炸。

## 比例与画幅

- 近景细节：主体占画面 45%–85%，保证关键部件清楚。
- 单体全身或完整物体：主体占画面 35%–70%，为弧流和负空间留出位置。
- 环境叙事：主体占画面 8%–30%，动作仍应可读。
- 巨构或纯景：主体可无；若用户要求尺度锚点，再使用小人物或小物体。
- 横向叙事优先 16:9；竖向单体优先 3:4；社交竖屏使用 9:16；用户指定比例高于默认。
