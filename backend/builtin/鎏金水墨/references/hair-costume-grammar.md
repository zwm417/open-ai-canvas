# 人物发饰与服饰语法

本文件只在人物、类人形态，或用户明确要求发型、头饰、服装时启用。它负责把“华丽、古风、仙气、鎏金”拆成可生成的结构关系，不负责决定人物性别、身份、眼睛状态或动作。

## 最高优先级

1. 用户明确的时代、文化、职业、现代/历史服装、发型和头饰优先于本文件。
2. 用户只要求材质风格时，保留其服装类别，只改变织物表面、金属工艺、金箔附着与光线。
3. 用户未指定造型时，选择一个发饰密度档位和一个服装堆叠；不得把“女子”自动等同于闭眼神女、凤凰冠或巨型头饰。
4. 非人物、无人空景、普通动物、建筑、植物、器物和纯抽象不得套用本文件。

## 发型底座

先写发型，再写饰件。发饰必须依附在可承重的发束、发髻、鬓后或发际结构上。

- 湿发近景：深黑或蓝黑发体形成成束整体，表面有稀疏冷青反光；只保留少量贴面碎发和黏连发束，不把每根头发均匀分离。
- 半束半披：上部发束固定成小髻或后束，下部长发保留运动；适合舞蹈、行走、风中、月夜与中等装饰密度。
- 低髻或高髻：为簪、梳、步摇或小冠提供明确承重点；髻体轮廓必须可见，不让饰件漂浮。
- 披发：适合雨雪、亲密近景与低装饰模式；可用单枚小梳、细簪或碎金箔，不默认头冠。
- 动态方向：发尾、贴面碎发与流苏总体服从同一风向、旋转方向或重力；只允许少量反向乱丝增加自然感。

## 发饰密度档位

每个人物只选一个档位。用户有明确要求时服从用户。

### A. 稀疏天气档

- 适用：雨、雪、风、近景、旅行、战斗、奔跑、脆弱或写实氛围。
- 造型：湿披发、低束或简洁发髻；单枚细金簪、小型旧金发梳，或只在湿发间附着少量碎金箔。
- 连接：发簪穿过发髻；发梳嵌在鬓后发束；不得同时追加巨冠与长流苏。
- 服装搭配：厚实赭金、橙褐、深青或黑漆感锦缎披风/外袍，露出一线朱砂或暖象牙内层；旧金磨损沿领缘和肩部褶皱出现。

### B. 平衡流动档（人物默认）

- 适用：舞蹈、月夜、水边、风中、梦境、叙事人物与全身像。
- 造型：半束半披、低髻配长发或稳定后束；一枚小到中等旧金花丝发梳、发簪或低矮小冠。
- 纹样：抽象卷云、卷草、羽片、花瓣或水纹；可以借用凤凰“意象”，但不生成真实鸟头、鸟身或展开巨翼。
- 连接：发梳固定在左/右鬓后或髻座；发簪穿过发髻；最多两束短珍珠/细金链从饰件下缘垂落。
- 服装搭配：深青蓝或蓝黑不透明内层 + 象牙白丝绸主体层 + 香槟金半透明外纱；长水袖或裙摆沿动作方向舒展。

### C. 仪式花丝档

- 适用：祭仪、王座、圣像、正面肖像、用户明确的华丽神祇或典礼场景。
- 造型：有边界的实心旧金花丝冕、冠或额饰，由发际与髻座承托；卷云、卷草、羽片和抽象凤纹形成镂空高浮雕。
- 连接：珍珠、细金链或步摇从冠体下缘对称或有控制地不对称垂落；长流苏避开眼睛、嘴唇和手势。
- 预算：头饰可华丽但不得遮住大半张脸、超过画框或成为比人物更强的独立金色雕塑。
- 服装搭配：蓝黑/深青不透明内袍 + 象牙白或银蓝丝绸中层 + 半透明香槟金外袍；精细金线集中在领缘、袖口、胸襟和裙摆。

## 连接三元组

每个饰件都用“饰件 + 固定位置 + 垂挂/运动关系”写成完整关系：

- 一枚旧金花丝发梳，固定在右侧鬓后发束中，两束短珍珠金链从下缘垂落。
- 一支细金发簪，水平穿过低髻，末端只带一颗珍珠，不接触脸颊。
- 一顶低矮镂空小冠，由发际和髻座共同承托，短流苏沿耳前垂下但避开眼睛。
- 少量碎金箔贴附在湿发束表面，由侧后方掠光显现，不漂浮成金粉。

禁止只写“华丽发饰、精美头冠、许多珍珠”。名词列表会导致漂浮、复制和错误连接。

## 服装三层堆叠

按需要从下到上编译；透明外层出现时，不透明内层不可省略。

1. 不透明内层：深青蓝、蓝黑或墨黑哑光丝绸/锦缎，贴身或具有明确衣襟，负责覆盖与动作轮廓。
2. 主体中层：象牙白、银蓝或暖灰丝绸，具有柔亮褶皱、衣领、腰封、裙摆或宽袖结构。
3. 半透明外层：香槟金、淡象牙或银蓝薄纱/欧根纱，能看见其后的内层与背景，边缘受光但不是塑料膜。
4. 表面工艺：细旧金刺绣、金线压边或贴附碎金箔，从衣领、袖口、腰封、裙摆、缝线和褶皱中选择 1–3 处。

厚实天气服装可把第 3 层替换为赭金或橙褐锦缎披风；现代服装保留现代裁剪，只采用相同的层次、织物与鎏金落点原则。

## 衣料与空间金液分离

- 水袖/薄纱：柔软、可折叠、受身体动作牵引，具有织物纹理和连续缝边。
- 透明金液：折射、带厚度、有亮边，从水面或空间独立生成弧流，背景可以透过它看见。
- 贴附金箔：扁平破碎，沿织物褶皱、刺绣或磨损边缘粘附。
- 实心花丝：只存在于发饰、扣件、腰封局部或结构性装饰，保持硬边和不透明。

同一分句不要把 gauze、liquid gold、filigree 和 gold leaf 写成并列同义词。先给每种材料指定位置与边界。

## 动作适配

| 动作或镜头 | 发饰策略 | 服装策略 |
|---|---|---|
| 舞蹈、旋转 | 平衡流动档；发梳或簪牢固固定，短流苏 | 不透明内层保持身体轮廓，长水袖/裙摆形成两条主运动线 |
| 奔跑、战斗 | 稀疏档；紧发髻、短簪、小梳，无长链 | 窄袖或收束袖口，衣摆不遮脚与武器 |
| 飞行、坠落 | 稳定后束或半束，小型饰件 | 外纱与发尾同向，避免衣袖包住手臂 |
| 静态仪式 | 仪式花丝档，可用有边界的大冠 | 完整三层服装，金线集中于礼仪结构 |
| 面部近景 | 发饰可提高工艺细节但减少数量 | 只露出有辨识度的领缘和肩部材质，不用大袖抢焦点 |
| 雨雪近景 | 湿披发或低束，单枚小饰件或无饰件 | 厚实粗粝披风、旧金磨损、少量朱砂内层 |

## 分支映射

- 梦幻透明鎏金：优先平衡流动档与三层丝绸/薄纱；透明金液是独立空间弧流。
- 水墨金箔世界：裙摆和袍袖可向湿墨、宣纸、树脂地形延展；织物边缘仍需可读，金箔顺褶皱附着。
- 雨雪湿光：优先稀疏天气档、湿发和厚实赭金/深青披风；装饰密度低。
- 花丝圣像：仅在仪式人物时使用仪式花丝档；冠饰与透明金液必须分层。
- 矿彩树脂梦境：可使用银蓝/矿物青丝绸、半透明玉质感面料片和旧金缝线，但避免整件衣服变硬壳。

## 最终检查

- 发型是否有结构和统一运动方向，而非只写长发。
- 每件头饰是否说明固定点；每束流苏是否说明起点并避开面部。
- 是否只选一个装饰密度档位，且与动作相容。
- 是否至少有不透明内层和一种明确主体织物；透明层是否有覆盖保护。
- 金线/金箔是否落在具体衣服部位；是否与空间金液和花丝金属分开。
- 是否保留用户的时代、身份、眼睛状态、姿态和服装类别。
- 非人物输出是否完全没有误加发饰、头冠、古装或人物。
