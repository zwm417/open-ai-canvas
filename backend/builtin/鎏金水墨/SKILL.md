# 鎏金水墨幻想提示词与画布协同

把用户给出的任意主体或场景编译为高质感、极具东方意境的“鎏金水墨幻想”艺术作品。
核心美学灵魂：**风格锁定材质透光度、流动光线与冷墨负空间，不生硬捆绑固定人物造型；让光金如流体般附着于主体肌理，形成虚实共生的东方诗意。**

---

## 主体自由原则

- **万物皆可入画**：主体可以是人物、群像、动物、神兽、植物、建筑、山水、器物或抽象形态。
- **保留原生事实**：始终保留用户明确给出的主体形态、数量、动作、表情、视角与时代特征。
- **杜绝刻板模板**：不因风格样本曾出现仙女而自动加入女性、闭眼、金冠或人脸；若用户指定黑豹、巨鲸或机械神像，严格按原主体呈现。
- **局部流金，克制用色**：鎏金系统是通过局部表面、内部脉络或空间光流生效，严禁把整个主体直接浇铸成黄铜金属块。

## 工业化执行标准 (双模执行管线)

### 模式一：画布 Agent 执行管线 (Canvas Agent Automation)
1. **画布感知与多模态审图 (`canvas_get_state` + `canvas_inspect_image`)**：
   - 启动时调用 `canvas_get_state` 读取当前画布节点与参考图资产。
   - 若画布上已有主体图片（角色、神兽或器物），**调用 `canvas_inspect_image(nodeId)` 观察画面细节**：
     1. 主体轮廓与结构特征（毛发流向、鳞片纹理、器物造型）；
     2. 既有色彩分布与暗部阴影深度；
     3. 姿态动态与受光方向。

2. **画布实体落位与拓扑连线 (`canvas_apply_ops`)**：
   - **鎏金方案节点**：调用 `canvas_apply_ops` 创建 `markdown` 节点（`nodeType: "markdown"`, `title: "鎏金水墨·艺术方案"`），记录：
     - 主体形态锁与材质分层（实心金属、透明金液、贴附金箔、湿墨黑漆）；
     - 单一主光源与暗青/蓝黑负空间留白策略；
     - 核心 ImageGen 中文提示词与 Midjourney 英文提示词。
   - **生图草稿节点**：调用 `canvas_apply_ops` 创建 `image` 草稿节点（`nodeType: "image"`, `title: "鎏金水墨-生成成片"`）。
   - **建立连线**：若有参考图片节点，在 `canvas_apply_ops` 中使用 `connect_nodes` 建立从源参考图至目标 `image` 节点的连线依赖。

3. **模型协商与原生出图 (`model_list` + `generate_media`)**：
   - 当用户明确要求“生图、出图、生成”时：
     1. 调用 `model_list(mode="image", referenceNodeIds=[...])` 查询当前生效的图像生成模型（如 `gpt-image-2.5` 4K 质量档位）；
     2. 经用户授权确认后，调用 `generate_media` 提交生成任务：
        - `mode`: `"image"`
        - `nodeId`: 目标 `image` 节点 ID
        - `title`: 节点名称
        - `prompt`: 完整中文/英文提示词（若有参考图，在描述中使用 `@图片1` 绑定）
        - `referenceNodeIds`: 引用的画布图片节点 ID
        - `size`: 默认 `16:9`（环境/叙事）或 `3:4` / `9:16`（单体立像）
     3. 通过 `task_get` 核验任务状态并将结果回写画布节点。

4. **动线美学排版 (`canvas_arrange_nodes`)**：
   - 节点创建与出图后，调用 `canvas_arrange_nodes(mode="flow")` 完成画布自左向右的工整排版。

### 模式二：生图/生视频工作台直达态 (Workbench Direct Mode)
- **开箱即用提示词卡片**：直接提取下方经过精细调优的 Midjourney V8.2 与 ImageGen / GPT-Image-2.5 提示词；
- **参数预设**：默认 `16:9`（宏大叙事构图）或 `3:4`（单体立像），采样步数与质量建议设定为高质量/4K档位；
- **推荐模型**：优先选用 `gpt-image-2.5` 或 `midjourney-v8.2`。

## 核心材料硬规则与视觉配方

每张图从以下材料中精选 2–3 种组合，严禁混成单一糊状金黄色：

1. **实心花丝金属**：不透明、精细镂空浮雕与冷硬金边，仅用于冠饰、器物、局部战甲或建筑骨架。
2. **透明琥珀金液/玻璃流体**：透明、折射、带高亮边缘的高透光流体，形成细丝、悬浮液滴或弧形光带；背景与主体必须透过金液清晰可见。
3. **贴附碎金箔**：扁平、破碎、沿山脊、树根、鳞片、衣褶或肌肉起伏贴附，由掠光照亮，自身不发光。
4. **湿墨/黑漆**：深黑、青黑底色，带湿润镜面反光与边缘水墨渗化，营造静谧冷峻的高级留白。

### 人物造型保护规则
- 仅在主体为人物时启用发型与服饰规范；
- 发簪与流苏必须有明确着力点，严禁悬空漂浮或穿透面颊；
- 金流特效必须与衣袖、裙摆明确分离描述，防止衣物熔化为金属泥。

## 交付前质量门槛

- 去掉人物后，本风格是否依然能完美附着于神兽、器物或山水风景；
- 是否明确区分了实心金属、透明金液与碎金箔，杜绝材质串线；
- 金色是否来自局部反射与材质，杜绝全屏大黄光、廉价页游感；
- 零本地污染红线：所有生成与数据流转完全依托系统画布节点，严禁在磁盘上生成任何临时脚本。
