# 长篇小说影视化方法

只在处理原著摄取、改编分析、分集结构或证据争议时读取本文件。

## 1. 摄取与分块

原稿只读。先创建源清单，再读取内容：

1. 记录文件路径、格式、编码、字数/页数、SHA-256 和授权备注。
2. 识别卷、章、场景和时间跳转。以章节与场景语义边界分块；超长章节再按事件边界切分。
3. 为每个块分配 `SRC-Vxx-Cxxx-Bxxx`，记录起止位置。
4. 每块提取事实、事件、人物状态、关系变化、场景、道具、伏笔和未解问题。
5. 章节摘要必须引用块 ID；全局判断必须能追溯到至少一个源块。

不要用滚动摘要覆盖原始事实。摘要可以更新，源定位和原文哈希不能更新。

## 2. Canon ledger

`analysis/canon-ledger.json` 至少包括：

```json
{
  "characters": [{"id":"CHAR-001","names":[],"facts":[],"stateTimeline":[]}],
  "relationships": [{"from":"CHAR-001","to":"CHAR-002","state":"","evidence":[]}],
  "worldRules": [{"id":"RULE-001","rule":"","evidence":[],"exceptions":[]}],
  "timeline": [{"eventId":"EVT-001","order":1,"time":"","place":"","participants":[],"evidence":[]}],
  "props": [{"id":"PROP-001","owner":"","stateTimeline":[],"evidence":[]}],
  "openQuestions": []
}
```

把三类内容分开：

- `source_fact`：原著明确支持。
- `adaptation_decision`：为影视化而改变，必须说明原因和影响。
- `assumption`：暂未确认，不能作为不可变事实或生成真实声明。

## 3. 改编诊断

对每条重要故事线回答：

- 主角想要什么，为什么现在必须行动？
- 阻力来自人物、制度、环境还是自身？
- 每次策略如何改变风险、关系或认知？
- 哪个选择使故事不可逆？
- 结局兑现了什么观众承诺？

建立“保留/合并/删减/重排/补桥”表：

| 原著元素 | 证据 | 决定 | 影视理由 | 对人物/伏笔/结局的影响 | 风险 |
|---|---|---|---|---|---|

删减前做依赖检查：删除人物、地点或事件时，查找其承担的线索、动机、证据、转折、情感和伏笔回收。缺失功能必须转移给其他元素，不能只删除表面情节。

## 4. 故事容量与集数

不要套固定集数。先估算：

- 必须保留的主线节拍数。
- 每个节拍完成所需的最少场次。
- 对白密度、动作复杂度和视觉停留时间。
- 单集必须完成的小弧线和结尾推动。

为每集创建卡片：

```json
{
  "episodeId": "EP-01",
  "entryState": "",
  "goal": "",
  "pressure": "",
  "turn": "",
  "emotionalPeak": "",
  "cliffhanger": "",
  "exitState": "",
  "sourceEvidence": [],
  "durationSeconds": 120,
  "sceneBudget": []
}
```

结尾钩子必须来自新信息、新选择、新风险或未完成动作。禁止把任意一句狠话、突然昏倒或无因来电当作通用悬念。

## 5. 阶段审核

每阶段使用 PASS/FAIL 和可修复问题，不用模糊分数替代判断：

- 原著证据：关键事实与变化都有定位。
- 戏剧价值：目标、阻力、升级、选择和后果成立。
- 可视化：心理内容已转成表演、行动、声音或环境。
- 连续性：称呼、关系、规则、时间和道具没有冲突。
- 合规：授权、敏感内容、事实声明和平台限制有记录。

只有阻断项全部关闭才推进；非阻断建议进入下一版本清单。
