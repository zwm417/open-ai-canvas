# 剧本与逐镜分镜标准

只在编写剧本、分镜表、关键帧或镜头生成提示词时读取本文件。

## 1. 标准剧本场次

每场至少包含：

```text
SCENE ID / 集-场
内/外景 · 地点 · 时间
预计时长：00:00
出场资产：CHAR- / LOOK- / LOC- / PROP-
Canon before / Canon after

可见动作与环境状态。
人物名
对白
（必要且可表演的动作提示）

声音/转场（仅在叙事必要时）
```

检查每场是否至少改变一项：信息、关系、目标、风险、选择、人物状态。若都不改变，删除或并入相邻场。

内部独白的转换顺序：

1. 能否由选择或动作表达？
2. 能否由停顿、视线、距离、道具或环境反应表达？
3. 能否由对手的误读和主角反应表达？
4. 只有叙事形式明确需要时才使用旁白。

对白检查：每句都应有说话目的、对象、潜台词和可见反应。避免两人轮流解释观众已知信息。

## 2. 场次到镜头

先定义场次的叙事任务，再决定镜头。一个镜头只承担一个主要变化，复杂变化拆分为：准备 → 接触/选择 → 结果。

每镜使用稳定 ID：`EP01-SC03-SH005`。分镜表字段：

| 字段 | 要求 |
|---|---|
| timecode | 精确起止时间，整集连续 |
| purpose | 本镜头改变什么 |
| framing | 景别、机位高度、角度、构图 |
| lens/camera | 焦段感觉与单一主运镜 |
| blocking | 人物、道具、前中后景关系 |
| action | 起始状态、动作路径、峰值、结束状态 |
| performance | 视线、表情、呼吸、停顿 |
| dialogue/audio | 说话人、台词、环境声、音效、音乐 |
| continuity | 轴线、方向、服装、伤痕、道具手、光线 |
| assetIds | 已批准资产 ID |
| transition | 与前后镜头的图形、动作或声音连接 |

## 3. 镜头覆盖

按场景需要选择，不机械套模板：

- 建立空间：只在观众需要理解地理关系时使用全景。
- 行动与关系：中景/双人镜头表现距离和调度。
- 信息与情绪：近景、特写表现决定、线索和反应。
- 对话：先锁轴线和视线，再规划主镜头、过肩、单人和反应镜头。
- 动作：为准备、接触、结果和空间重新建立提供覆盖。

剪辑优先级：情绪 → 故事 → 节奏 → 视线 → 二维画面 → 三维空间。技术连续不能牺牲关键情绪，但违反轴线必须有明确意图和过渡。

## 4. 关键帧

每镜默认三个锚点：

- `start`：承接上一镜的可验证状态。
- `peak`：本镜最重要动作或情绪变化。
- `end`：提供下一镜可接的明确最终状态。

完全静态镜头可减少锚点，但必须记录 `staticReason`。多宫格只用于审片；最终视频输入使用独立关键帧。

关键帧提示词为自包含段落，按顺序写：

1. 稳定角色 ID 对应的可见身份锚点。
2. 当前服装、伤痕、道具和状态。
3. 场景拓扑、时间、天气和主光源。
4. 具体瞬间的动作与表情。
5. 景别、机位、构图、镜头感觉和景深。
6. 色彩、材质、画风和连续性约束。
7. 禁止项：额外人物、服装漂移、道具换手、文字、水印、畸变等。

## 5. 视频镜头提示词

图生视频已经能看到输入图，不要重复整幅静态描述。写清：

- 主体从什么状态移动到什么状态。
- 动作路径、速度曲线、重心和物理反馈。
- 表情或关系在何时发生变化。
- 相机最多一个主要运动，必要时一个次要修正。
- 环境动态、光线变化和准确时长。
- 最终画面需落在哪个可剪辑状态。

镜头提示词禁止使用“更有电影感”“震撼”“高级”等无法执行的抽象要求替代动作、构图和光线。

## 6. 时间线检查

- 同一集镜头无重叠、无空洞，除非明确设计黑场或静默。
- 对白时长符合实际语速，并为反应镜头留时间。
- 每场预计时长等于所属镜头时长之和。
- 每集时长等于场次或镜头时长之和。
- 镜头结束状态与下一镜开始状态的动作、视线、道具和声音相容。
