# 视频、声音、合成与终检

只在生成逐镜视频、音频、字幕、合成工程或最终交付时读取本文件。

## 1. 逐镜生产记录

每次平台请求记录：`shotId`、目的、输入资产 ID、输入文件、提示词版本、平台任务 ID、输出路径、审核状态和重做原因。一个镜头一个可重试单元。

镜头验收：

- 人物身份、服装、伤痕、道具和场景状态正确。
- 动作起点、峰值、终点和时长与分镜一致。
- 相机运动可理解，无意外变焦、漂移或轴线跳变。
- 无脸/手/肢体/物体形变、闪烁、穿模和纹理跳动。
- 对白说话人、口型和反应镜头相符。
- 最后一帧可与下一镜剪接。

不要因为某个镜头失败而自动重做整集。优先修改提示词、锚点或该镜资产组合。

## 2. 声音分层

建立五层声音表：

1. 对白：说话人、语言、情绪、语速、起止时间。
2. 旁白：只在叙事形式需要时使用。
3. 环境声：建立空间和时间连续性。
4. 动作音效：与可见动作对齐，避免无画面来源的泛滥音效。
5. 音乐与静默：定义主题、段落、拍点、进入/退出和授权。

对白、旁白、环境声、动作拟音和音乐意图在分镜阶段锁定，并随 `generateAudio=true` 的逐镜视频请求通过智影原生工作台 原生生成。用户提供音频时记录来源和授权。保留验收合格的原生对白、环境声和拟音；只有背景音乐明显不符合成片或接缝跳变时，才通过 智影工作台 生成或使用获授权音轨替换/调整 BGM。

## 3. 字幕与文字

- 对白字幕的原文、说话人、开始时间和结束时间必须在分镜阶段确定并交给视频模型逐镜生成；片名、集数、时间地点、演职表和精确法务文字可在后期确定性叠加。
- 使用最终原生对白音频校验字幕同步；出现偏差时优先重做对应镜头，只允许修正时间误差，不得在后期重新编写一套字幕。
- 检查安全区、字号、行数、断句、移动端可读性和遮挡。
- 画面生成阶段避免让模型自行发明招牌、品牌或法务文字；已由分镜锁定的对白字幕除外，必须按原文和时间配置生成。

## 4. 智影剪辑与后期合成 合成

- Composition 从交付规格读取宽高、FPS、总帧数和音频设置。
- Remotion 动画使用 `useCurrentFrame()`、`interpolate()`、`spring()` 和确定性数据。
- 禁止 CSS transition、计时器、`Date.now()` 和未设种子的随机数。
- FFmpeg 用于编解码、音轨混合、响度、代理、抽帧和最终技术检查。
- 先渲染首尾帧、镜头边界、字幕密集帧和复杂合成帧，再渲染低码率审片版，最后渲染母版。

## 5. 六层终检

### 原著层

关键因果、人物弧、世界规则、伏笔和改编决定可追溯；没有把假设伪装成原著事实。

### 剧本层

场次可拍、时长成立、对白可演、每场推动故事，业务/证据/连续性/合规审核全部 PASS。

### 资产层

稳定 ID 正确，角色、服装、场景拓扑、道具状态和批准版本一致，无占位素材。

### 镜头层

时间码连续，动作、轴线、视线、光线、口型和首尾衔接通过，无明显生成瑕疵。

### 声音层

对白清楚，音乐与音效来源明确，同步、平衡、峰值和整体响度符合发布平台。

### 技术层

最终 MP4 存在且非空，可解码；分辨率、画幅、FPS、时长、音轨、字幕、色彩和文件大小符合规格。

## 6. 完成门禁

以下任意状态都不能写“成片完成”：

- 只有小说分析、剧本、分镜或提示词。
- 只有多宫格或关键帧。
- 平台任务已提交但未成功返回。
- 只有逐镜视频但未合成声音和时间线。
- 已渲染但未完成六层终检。

执行项目终检：
- 检查故事大纲、角色/场景资产卡、分镜故事板及视频镜头完整性；
- 检查视频时长、画幅、对白口型与音画同步连续性；
- 检查通过且人工验收为 PASS 后，即可交付发布。
